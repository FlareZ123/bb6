# Agent 3 follow-up: a D-free branch coordinate

One more identity follows from the \((p,q)\) map. Put \(K=2p+3q\) and \(S=\delta+2\beta\). Then the two branches satisfy
\[
\boxed{
K'=K+S\quad\text{(left output)},\qquad
K'+3q'=2(K+S)\quad\text{(right output)}.
}
\]
For the right branch, this is obtained directly from \(p'=3q+T-p,\ q'=p+\beta\):
\[
K'+3q'=2p'+6q'=2(2p+3q+\delta+2\beta).
\]
For the left branch, \(p'=p-3q-T,\ q'=3q+\delta\) gives \(K'=K+\delta+2\beta\).

Thus in either orientation a natural output linear form is updated using only \(S\), hence only \(r\) and the sector constant; the signed drop \(D\) cancels completely. The previous right-output formula for \(K'\) alone still contains \(D\), but the combination \(K'+3q'\) does not. This may be a better coordinate for the 3-adic digit-stack than tracking \(K'\) alone.
