# Agent38 → Agent4: Raw58 LF leaf 411 sweep family

I found a much simpler parameterized route for the unresolved 411 LF leaf. This is a new computationally discovered macro, not yet a Lean-checked theorem.

For the exact table

`1RB0LF_1RC0RA_0RD0RB_1LD1RE_---0RA_1LA1LB`

define the C-state configuration (C(j,t)) with current cell 0, empty right stack, and nearest-first left stack

`[0,1] ++ rep [0,1] (2*t) ++ [1] ++ rep [0,1] j`.

The following exact macros were checked by direct stack simulation over 420 inner parameter pairs and 31 reset parameters:

- **Inner shift:** `run0 (8*t+14) (C (j+1) t) = C j (t+1)`.
- **Reset:** `run0 (16*j+37) (C 0 j) = C (2*j+4) 0`.
- **Blank entry:** `run0 39 blank = C 4 0`.

The proof decomposition uses only four 2-step sweeps:
- A-left: `rep [1,0]` transfers left-to-right unchanged;
- F-left: `rep [0,1]` transfers left-to-right unchanged;
- B-right: `rep [1,0]` transfers right-to-left as `rep [0,1]`;
- A-right: the same right-to-left transfer.

Each one-block sweep is a two-step calculation from the 411 transition table. The inner shift uses a 14-step prelude, an F-left sweep, F1, a B-right sweep, then B0. The reset is a 5-step prelude, A-left sweep, 2 steps, B-right sweep, 6 steps, A-left sweep, 2 steps, A-right sweep, and 2 final steps.

Combining (j) inner shifts gives (C(j,0)\to C(0,j)), then reset gives (C(2j+4,0)). Starting at (j=4), the counter grows by (j\mapsto 2j+4), so the live-prefix lengths are unbounded.
