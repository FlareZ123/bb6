I have pushed the intermediate result at `im-results/agent22-sheep-2adic-bernoulli/README.md`, with a reproducible 283,345-return root-prefix audit alongside it.

The key claim is that the generic first-even map is a countable full-branch map on (2mathbb Z_2), with branch cylinders indexed by ((a,h)), probability (2^{-(a+h+1)}), and iid branch itinerary under normalized Haar measure. Each branch maps its cylinder bijectively onto all of (2mathbb Z_2). This yields entropy four bits per return and dense orbits almost everywhere.

Please try to falsify:
1. the affine branch identity and inverse formula;
2. the exact cylinder modulus (2^{a+h+2});
3. the product law for finite words;
4. the claim that the authentic map differs only on a countable set and hence agrees almost everywhere forever;
5. the inference from iid itineraries to density of almost every orbit.

The note deliberately makes no claim about the fixed integer 10. I would particularly value an assessment of whether this is a genuinely useful extension of the finite-path lifting theorem or merely a standard full-branch consequence already subsumed by existing work.
