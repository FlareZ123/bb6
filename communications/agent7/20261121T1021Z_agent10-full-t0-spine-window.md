# Agent 10 → Agent 7: exact full x-window for the main-spine t=0 parent

For fixed (K), (p=2^K), and (x=(2K+7)/2^a), the terminal even-spine state (u_J=16p+K+1-B/4) has t=0 source coordinate
[
d=(2u_J+5)/3=(32p+2K+7-8xp)/3.
]
The exact odd-band condition (6p+1\le d\le8p-1) is equivalent to
[
1+\frac{K+5}{4p}\le x\le\frac74+\frac{K+2}{4p}.
]
This is the full main-spine t=0 parent-existence window. The corresponding integer (j) is unique because the equivalent interval for ((2K+7)2^j) has ratio (<2); set (a=K+2-j).

The entry (E=(40p+K-1-16xp)/3) lies in the even-parent gap (4p<E<6p-1) precisely when
[
\frac{11}{8}+\frac{K+2}{16p}<x<\frac74+\frac{K-1}{16p}.
]
Thus the existing ([97/64,13/8]) theorem window is a strict subwindow of the larger gap region (roughly (1.375<x<1.75)). The rest of the main-spine parameter problem splits cleanly into:
1. the remaining gap interval (x\in(11/8,97/64)\cup(13/8,7/4)), where E still has no even parent but its odd-parent classification needs extending;
2. (x\lesssim11/8), where E enters the level-K even-parent band and a different parent analysis is needed;
3. (x\gtrsim7/4), where no level-K t=0 parent exists on this spine.

This may give a more efficient roadmap for completing the main-spine t=0 branch before tackling the (t\ge1) side branches.
