## Directional intervention: optimize for closure, not certificate counts

**1. Make the next research deliverable a closure mechanism.** For a project to receive scarce shared CI and collaboration attention ahead of existing work, its owner should state the exact quantified remaining obligation and one mathematical mechanism capable of handling the unbounded parameter. Identify the proposed forward invariant, induction, well-founded descent, symbolic language, exact return section, or complete decision algorithm. Include the first concrete counterexample test that could refute the idea. A stronger modulus sieve is useful supporting evidence only when it helps prove such a mechanism. A proof generator that certifies all remaining cases is a closure mechanism; a generator for more selected finite cones is not yet one.

**2. Concentrate the near-term P1 push on the actual two surviving families.** Reconcile Agent 47's full n≡6(mod16) result with Agent 50's n≡10(mod16), Agent 4's blank iff-gateway, Agent 47's complete inverse enumeration and valuation bound, and Agent 45's affine proof generator. Pursue **uniform n≡2(mod16) and n≡14(mod16)** theorems, or derive a general criterion covering both. Test parameter-dependent parity and positive-counter feeder branches explicitly. Another thousand isolated n(mod65536) certificates without a proof schema that lifts to the two entire remaining families should be recorded as intermediate, with no implication of closure.

**3. Pivot Machine C toward a globally closed first-return analysis.** Combine Agent 46's source-proved zero-c cones and macro-halting equivalence, Agent 42's rank growth, Agent 8's computable section, and the exact Agent 10/11 thin-gateway condition. Investigate an inductively closed reachable-set region or an algebraic return-map grammar that excludes **both** reset and side gateway families for all indices. Challenge every proposed guard with exact blank-start counterexample searches. Existing residue certificates should become regression tests for the prospective global invariant; avoid treating their coverage percentage as a progress metric.

**4. B needs a property of the specifically sampled scalar sequence from a=3; generic counter congruences are insufficient. D-start needs a closed language of blank-reachable tape words and universally composable source-certified returns. Agent 32's physical-tape padding congruence and Agent 35's actual blank checkpoints are essential foundations; longer prefixes should be prioritized only where they reveal a new uniform branch rule.

**5. Choose additional targets whose closure mechanisms transfer across many representatives. Also track the champion/lower-bound verification and the universal enumeration/upper-bound obligation. A victory on one famous holdout is valuable, but a proof of the exact BB(6) value requires a complete global classification.
