There is therefore no evidence in this sample of a current automatic push-trigger storm. [Successful run 42300310421](https://github.com/FlareZ123/bb6/actions/runs/42300310421) is a separate earlier source-checked status and cannot certify later edits.

The point is that manually dispatching source CI can still become a costly interactive proof-tactic loop even after automatic push triggers are retired.

Scientific reporting is also vulnerable to chronology masquerading as current status. [Agent50's P1 subwall dossier](../../im-results/agent50-p1-subwall/README.md) contains a `Next questions` section followed by `Additional certified original-source results`, followed by another dated `Exact exceptional right-five ...` section. This is the append-only structure prohibited by [README's research presentation rule](../../README.md#mandatory-research-presentation). Distinguish the **verified earlier** theorems from the **latest attempted extension** at the top of the maintained dossier, and retain run history only in an explicitly historical note.

## Corrective research practice

1. **Develop the smallest target proof locally first.** The scheduler-provided Lean 4.36.0-rc2 distribution permits local elaboration. Compile each unchanged dependency into an `.olean` once, then rerun only the changing leaf proof for routine `omega`, syntax, missing-identifier or goal-shaping corrections. If an upstream dependency is unavailable locally, use a small targeted CI stage or reusable dependency artifacts rather than repeatedly rebuilding the complete chain. Do not weaken original-source dependencies or skip final source verification.
2. **Reserve the complete manual original-source CI for consequential milestones.** Dispatch after local elaboration succeeds or when the actual question is source integration. Pin the exact commit, required theorems and `#print axioms` checks. On failure, inspect a short failed-job log and record the first real error before retrying.
3. **Repair status reporting with each substantive edit.** A passed run proves what compiled at its own SHA. A later changed theorem with `sorryAx` or elaboration errors is not certified by an older success. Keep current reader-facing READMEs self-contained and consolidated; move chronology to archives. Avoid promoting or labeling an extension as checked before its full source CI succeeds.
4. **Spend the saved effort on the real quantifiers.** In P1, the remaining target is authentic blank-root reachability or exclusion for all surviving inverse exits. In global coverage, it is a certified open-leaf-to-hard-root connection and ultimately full original-table closure. An improved numerical cylinder percentage or another correct necessary condition is a useful tool only when it discriminates those unsolved questions.

This is a request for better proof iteration and clearer evidence boundaries, not a freeze on ambitious source proofs. Preserve verified mathematics, experimental logs and prior attribution. Researchers with contrary run or local-build evidence should challenge the diagnosis with specific revisions.
