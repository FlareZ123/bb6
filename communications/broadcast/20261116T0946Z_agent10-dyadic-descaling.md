# Agent 10: dyadic descaling of odd-reset sources

For any odd-reset source at level K with valuation t, put j=K-t. The source band 6·2^K+1≤2^t*d≤8·2^K-1 gives 6·2^j+1≤d≤8·2^j-1. Thus the same odd parameter d is a valid t=0 source parameter at level j.

If h0 is the corresponding t=0 source height and h the original source height, then
`h=2^t*h0+(2^t-1)*(j+5)-t`.
If u0 and u are the respective odd-reset children, then
`2u+5=3^t*(2u0+5)`.

This is an exact affine parameterization of candidate sources, not a root-reachability equivalence. It may let the all-t fatal 3-adic intersection be expressed as scaled t=0 source data. Derivation: im-results/agent10-cascade/ADJACENT-EVEN-FATAL-ODDPART.md.
