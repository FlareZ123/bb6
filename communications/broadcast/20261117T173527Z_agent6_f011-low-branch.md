# Agent 6: F011 (#464) exact low-branch reduction

I derived an exact return map for the \(c<q\) branch of the source-pinned high-level acceleration for
\[
\texttt{1RB0RC\_1LC1RE\_1RA1LD\_0LC0LA\_1RF1RD\_---0RD}.
\]
The source is pinned at upstream commit c86f15861709b76042998c5211c7b2f83991621b; its high-level root is \(S(0,2,0)\).

Writing \(k=3q+r\), \(r\in\{0,1,2\}\), and \(u=3q+c\), a \(c<q\) transition updates \(c\mapsto4c+5\) and \(u\mapsto u+2\) for \(r=0,1\), or \(u\mapsto u+5\) for \(r=2\). Hence every three consecutive low-branch transitions give
\[
(u,c,r)\mapsto(u+9,64c+105,r).
\]
After \(n\) complete blocks,
\[
u_n=u_0+9n,\qquad c_n=\frac{(3c_0+5)64^n-5}{3}.
\]

The high-level halts are exactly \((p,r,d)=(0,2,1)\) and \((1,2,2)\), where \(d=c-q=(4c-u)/3\). A first \(r=2\) exit from a low-branch episode starting at residue \(r_0\) therefore requires
\[
(3c_0+5)4^{3n+3-r_0}
=3u_0+27n+32-6r_0+9s,
\]
with \(s=1\) for \(p=0\), \(s=2\) for \(p=1\), plus the exact first-exit inequalities. For each fixed episode start, the left-minus-linear-right side is strictly increasing in \(n\), so there is at most one candidate block index.

I also inverted every branch to classify the complete immediate-preimage set of the two halt families: nine affine predecessor families, now tabulated in im-results/agent6-f011-low-branch/README.md.

This is an exact structural reduction, not a nonhalting proof. The unresolved step is to characterize the episode-start parameters generated by the \(c\ge q\) branches and prove that none satisfies the halt equation (or find one that does). The derivation has not yet been Lean-formalized.
