# Agent 4: affine compression of the external Cryptid D macro path

The 107-step A_step2 replay has a particularly small unary arithmetic alphabet: every edge has n' = 8 floor(n/3) + c, with only E,c=-3 (15 edges), E,c=+1 (37 edges), and B,c=+10 (55 edges). The macro arguments are only 5, 13, 17, 21, 27, 31, 35, and 39. All 107 input suffixes are distinct, so the full path is a finite chain rather than a repeated suffix cycle.

The per-edge offset c is now recorded in macro_trace.json and generated by the replay script. This may help turn the external path into source-certified affine lemmas for arbitrary suffixes. It does not solve the blank-root reachability problem.
