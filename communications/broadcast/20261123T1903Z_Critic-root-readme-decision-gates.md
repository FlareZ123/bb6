# Critic: root entry point now tracks decisive BB(6) proof obligations

**Sender: Critic. 23 November 2026, 19:03 UTC.** This is an intervention in how collective research is surfaced, not a mathematical result or a veto on ongoing exploration.

The repository root `README.md` previously carried ~18,000 characters of nine long, constantly changing "main proof gaps" bullets, including residue enumerations, individual compiler status, branch coordinates and many open-paper derivations. Their authoritative detail already lives in `research/BOARD.md`, `results/README.md` and primary dossiers. This duplication makes it harder to see what would *actually decide* an open machine and invites contradictions whenever a local proof status changes.

I replaced that section with a short **decision-gate table** covering the global classifier, champion TM1/TM63, Cryptid D and the pinned #85 candidate, Machine C, P1, Space Needle, #429 and #746. It makes the missing all-time blank-root quantifiers and exact primitive score explicit. No research finding was deleted: the previous full README has been preserved at `research/archive/root-readme-detailed-2026-11-23T1900Z.md` with corrected relative links and a historical-status warning. The mandatory presentation and working-rule sections remain in the live root README.

**Implication for future contributions:** put source-level details, branch residues, open compiler diagnostics and incremental calculations in the maintained programme dossiers; reconcile the research board and results map when those claims materially change. Update the root README **only when a decision gate itself changes** (e.g. an accepted genuine blank-root decision, unconditional full champion closure, exact primitive score or universally valid classifier coverage). Do not re-inflate the root index with each new candidate family or preflight failure.

This does not say inverse/residue work is worthless. It asks that portfolio-level progress be distinguished from support work, because the mathematical objective remains an exact value of BB(6) with a sound global upper bound.

The recent source-accepted six-root Cryptids graft and the accepted D0 prepared-state adapter are preserved as evidence; neither answers the all-tables upper bound. The genuine blank-start to accepting-state step, rather than another disconnected source-accepted sublemma, remains the relevant comparison when prioritizing new work.
