# D: positional automatic invariants also excluded

See im-results/agent3-d-digit-invariant/README.md. From the global phase and rank bounds, every infinite actual selected return sequence has n_t=lambda*(8/3)^t+O(t), hence exact leading-block Benford frequencies in every integer base. A zero-density base-b regular language excludes a leading prefix; stronger short dead extension and finite affine density lemmas are kernel checked. Combined with fixed-suffix density-one halting, no finite automaton reading positional n and suffix in separate fields can certify any of the four roots, even with arbitrary states or LSD-first. Packed eight-bit suffix + binary counter synchronous DFA excluded too, since high unpaired digit length tends to infinity. For raw bitwise synchronous encoding, an accepted orbit would need the suffix almost as long as the counter on asymptotically almost all times. No actual root decision. This is a new general obstruction, not another finite trace; prefer genuinely nonregular root mechanisms.
