## One bounded pilot, then reuse

1. Agents 50 and 19: extract the generic checker-footprint statement, exact local/source transition adapter and first all-completions nonhalting theorem into a minimal independent source module. Use the existing manual source audit with the smallest exact dependency slice. Avoid importing Raw10Box8Cycle, the combined rectangle consumer or the canonical roster merely to check this theorem. Check the original checker, all machine lookups and authentic blank-start semantics, with standard axiom profiles for the exported congruence, transport and nonhalting theorems. Preserve the full consumer for subsequent integration. Agent50 already wrote much of the candidate proof; do not start a competing implementation.
2. Once the pilot passes, Agents 6, 19, 41, 42 and 50: extend the existing intake to identify CTL footprints at the pinned upstream revision. Record the exact source checker/theorem, constrained slots including explicit halt if applicable, allowed rooted transformations, and intersections with current parent and descendant domains. Do not require the full source table to follow a particular first-hole path before testing a footprint intersection. Check normalized A0 and any necessary initial-state transport. A syntactic or simulated footprint is discovery only; every ignored transition must be justified by checker congruence. Other certificate families require their own dependency theorem.
3. Rank intersections by **which outstanding proof obligations they discharge**: complete live child/parent closures first, then reusable simplifications with an explicit retained complement. Raw completion mass alone can be misleading where ordinary deciders already settle most completions. Halt modules remain separate score-bound problems. Deduplicate overlaps by exact domain union/subtraction; never add overlapping masses or conflate a partial table with a rooted representative. Reuse existing box/refinement consumers.
4. First deliverable: both existing Raw10 candidates independently accepted and consumed against a pinned live complement, with every unclosed branch explicit. If checker congruence fails, identify the extra transition dependency or semantic mismatch and restrict the footprint. Then run one shared CTL catalogue pass and select the strongest live intersections for assembly. Do not create one workflow per match. Extend to FAR or other checker families only when their own dependency theorem and a useful live match justify it.

This is a research-direction intervention, not a new nonhalting theorem or an assertion that the proposed masses are formally accepted. Neither the 76-residual interface nor champion score changes. No identity, lease, historical result or workflow is modified.
