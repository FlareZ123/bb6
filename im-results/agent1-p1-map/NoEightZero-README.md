# Agent 1: a global mod-8 blank-orbit reset restriction

**Status:** rigorously verified intermediate reachability theorem for a previously published BB(6) accelerator. This does **not** decide the holdout, prove a new BB(6) bound, or establish the value of BB(6).

Machine: `1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_---0RE`; the exact accelerated map `T` starts from `(2,1)` on blank tape as in [Google DeepMind Cryptids' formally verified reduction](https://github.com/google-deepmind/cryptids/blob/main/BusyBeaver/BB6/M_1RB1RD_0LC1RA_1LA1LC_1RA1LE_1RF0LD_HHH0RE.lean).

## Main all-time theorems

The full standalone Lean chain `PosEvenForm.lean`, `ResetGate.lean`, `NoEightZero.lean`, and `NoOneResets.lean` defines the published `G,T` recurrence independently, with forward reachability `Reach` generated by `Reach.init : Reach 2 1` and `Reach.next` from exact `T` transitions.

1. **`blank_no_zero_mod_eight`:** For every natural `b`, `Reach b 0 → b%8 ≠ 0`. Hence the actual blank-entry accelerated orbit can never have zero second counter and first counter a multiple of eight, at any finite time.
2. **`blank_no_two_one_mod_eight`:** For every `j≥1`, `¬Reach 2 (8*j+1)`. This removes an infinite family of possible positive reset states, while the original `(2,1)` remains the initial state.
3. **`blank_no_two_twelve`:** `¬Reach 2 12`, an exact small exceptional preimage exclusion required by (1).
4. **`even_left_power_shape`:** `Reach b d` with even `b` and positive even `d` implies `b+12=14*2^j` for some natural `j`. This normal form was already independently proved by Agent 7 as `blank_even_hub_power` and is reused in the independent proof here.

These statements are all universal over *every* finite reachable prefix, with no finite iteration bound.

## Proof structure

A comprehensive backward analysis of `T a c=some(b,0)` for `b%8=0` has only the following cases:

- `c=1`: then `b=a+2`, so `a%4=2` while `a` is even and the reached positive-right hub `(a,1)` must satisfy `a=2` or `a%4=0`. Neither alternative permits `b%8=0`.
- `a` even and `c>1`: the only zero-output case is `c=2`, producing `b=a+3` odd, impossible for `b%8=0`.
- `a` odd and `c=3`: the `G(a/2,1)` output has odd second coordinate, so cannot output zero.
- `a` odd and `c>3`: `G(a/2+1,c-2)=(b,0)`. A formal `G_even_output` lemma proves any even-second drain output must be from its direct high branch. Thus `b=2a+6` and `c=a+5`. A previous reachable positive-right hub must be `(a-3,c+2)`; the global even-left mod-4 invariant forces `a=5`, hence this predecessor is exactly `(2,12)`, already excluded.

For `(2,12)`, the only immediate predecessor is `(11,0)`. Inverting that transition gives either `(9,1)` (requiring forbidden positive-right even-left `(6,3)`) or `(8,2)` (forbidden because `8+12=20` is not `14·2^j`). Every branch is exhausted with Lean proofs.

The reset corollary follows because the only incoming transition to positive-right `(2,d)` is from `(d-1,0)`. For `d=8j+1`, `d-1` violates the main theorem. The initial state `(2,1)` is separately handled.
