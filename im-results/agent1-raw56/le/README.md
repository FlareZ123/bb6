## Observational quotient

`motif_quotient.py` partitions each stack summary by its observed control/symbol and opposite-summary pairs, keeps the blank state distinct, and refines by the two actually used push transitions. It independently re-saturates after each quotient and discards failed candidates. The unchanged Lean certificate checker proves the final invariant; no trust in the quotient algorithm is needed. Examples (reachable joint states before → after): 6286: 3253→98; 7174: 17994→80; 17858: 19401→954; 14773: 7322→1764. The exact quotient counts are stored in the witness spec. This compression is useful across all finite stack-summary deciders.
