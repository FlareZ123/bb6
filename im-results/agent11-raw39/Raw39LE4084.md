## Invariant discovery

A 100,000-return finite trace did not query F1. This is not an all-time proof. Lazy independent stack abstractions using bounded suffixes, run/alternation histories and modular counters have so far produced spurious bad states or exceeded their state cap.

In particular, dropping the left constraints entirely allows the right-only sequence (implicit trailing zeroes):
ε → 11 → 101 → 1001 → 10001 → 0100001 → 00001 → 111 → 1011 → 010011 → 0011.
Thus unrestricted right projection cannot certify the actual orbit. A certificate must retain additional correlation, or operate at a different section.

Whole-tape regular rewriting uses the word reverse(L)#R and rewrites each adjacent head-containing pattern exactly, so it preserves left/right correlation. Finite backward bad-language closure through 24 return steps produces a minimal DFA with 1,473 states; this is only a bounded exclusion. The missing mathematical object is an inductive invariant satisfying `Closed` or `Guarded`. Fixed-window history-annotated CPS, macro-role tagging, and finite factor abstractions have not yet closed the leaf. No Raw39 parent-cover decrement is claimed.
