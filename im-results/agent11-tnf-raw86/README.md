These independent derivations are alternate proofs of fifteen existing open-leaf recurrences, not a new roster removal. Local entry/growth theorems compiled using Lean 4.36.0-rc2 against copied exact zipper/sweep primitives; original-source nonhalting bridge and full tree are uncompiled here.
