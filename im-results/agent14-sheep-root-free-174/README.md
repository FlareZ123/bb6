## Complete all-k arithmetic argument

For a first-even root target `R=2^j` with `j=J+122472*k`, the prior original-source-checked inverse equations cover all even incoming edges. Such a source has hidden valuation `h` with `2^j=1+3^h*u`; generic source valuation a and odd part v satisfy:
```
3^h*(2^(a+1)+1)*v + 2*a*3^h + 2^(h+1) =
    2^(j+h+1)+3*3^h.
```
The exceptional odd-part-three branch satisfies:
```
3^h*(3*2^a+a+2)+2^h=2^(j+h).
```
Write `D=3^h, C=D−2^h, K(a)=D*(2*a−1)−2*C` and `M(a)=D*(2^(a+1)+1)`. The generic necessary condition is `2^(j+h+1)=K(a) (mod M(a))`.

For every certified J, the exact 3-adic bound is `H=2+v3(J/2)`, equal to 5, 6 or 7. The checker verifies `2^J≠1 (mod 3^H)`, `2^J=1 (mod 3^(H−1))`, and `2^P=1 (mod 3^H)`. Thus h<H for every k. For each h, calculate the finite threshold A at which `1<K(A)<2^A` and `2^A≥2D`; the classical odd Fermat-modulus gap, separately kernel-proved in `SheepOddGap.no_power_signed_small_odd`, excludes **all a≥A** by a one-step monotonicity induction. For each 1≤a<A, set `o=ord_M(2)`, `q=o/gcd(o,P)`. Exact full modular-period checking of all 0≤t<q excludes every low generic source valuation for every k.

For the exceptional source branch, define e=floor(log2(3D)), g=e−h, L=3D−2^e, U=2^(e+1)−3D. Every row verifies at j=J:
```
L*2^J > 2^g*C
U*2^J > 2^(g+1)*(D*(J+3)−C)
U*2^J ≥ 2^(g+1)*D.
```
These bounds are enough for the already proved exponentially growing signed-gap dichotomy, and persist for all j≥J. They exclude **all exceptional a**, with no search cutoff.

The script certifies all 174 classes from scratch with **6258 generic low rows**, **14982 full-period representatives**, and **966 special-source gap rows**. It checks all periods by direct modular multiplication; an independently run SymPy `n_order(2,m)` audit agreed for all **55 distinct moduli** used in the final 174 classes, with maximum multiplicative order **21870**. The 174-class sorted list's SHA256 was reproduced independently.

**Boundary of the scan:** Of 567 candidate roots `J=648+216t`, 386 classes have at least one surviving *necessary* generic congruence and cannot be called predecessor-free by this method. Seven further classes `J=17496,34992,52488,69984,87480,104976,122472` have nonuniform hidden h because `v3(J)` exceeds the valuation supported by P; the checker explicitly leaves them unclassified. The 174 certified classes are genuine unconditional exclusions. They make no statement about the other 393 candidates or the rest of the true blank orbit.
