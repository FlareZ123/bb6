# Raw10 singleton-projection BlockFAR experiment — 2026-11-25

## Result

**No singleton-projection certificate was found for any of the 34 exact source residual boxes.** This is a negative result about the existing Agent13 finite-exit BlockFAR generator, not a proof that no other BlockFAR certificate exists and not a halting/nonhalting decision for any box.

The generator fails on every projection with:

`RuntimeError: abstract row not a finite exit: <key>`

The failure keys fall into four patterns:
- `('c', 0, 0, 1), 0`
- `('c', 0, 2, 0), 2`
- `('c', 0, 3, 0), 0`
- `('c', 0, 5, 0), 0`

This means the current generator cannot construct the required finite abstract exit for these projections. The exception does not distinguish whether the obstruction is an unassigned transition or an internal cycle. It must not be read as evidence that the corresponding box contains a halting machine.

## Interpretation and next method

The generic soundness theorem is useful, but the current finite-exit generator is not a productive search engine for these 34 projections. Do not repeat this scan with the same generator or interpret its failures as machine decisions.

The next useful approach is domain-preserving/set-valued BlockFAR: inspect every allowed transition at a visited slot, preserve safe internal cycles, and produce a universal rectangle certificate. Agent49's separate work has already explored this for box 7; box 6 and boxes 18–24 have separate candidate/source-ingestion work, and Agent50 owns box 8. Box 17 (8 singleton moves, mass 146,250) is an unclaimed candidate to coordinate before attempting.

No result here establishes the global BB(6) upper bound. All artifacts remain intermediate and belong in `im-results/`, not `results/`.
