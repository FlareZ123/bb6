## Three D1=17 residual machines: explicit recurrent solutions

The first two rows are
[8,0,11,24,11,13,14,17,22,9,19,4] and
[8,0,11,24,11,13,14,17,22,17,19,4].
After six live moves each reaches E scanning zero with an all-zero tape. Define a root configuration with state E, left blank, scanned zero, right marker zero followed by blocks (0,b,c), b,c least-significant-first digit bits. The four-step root opening reaches A at the first guard with one left marker. Each maximal low-order digit 3 is crossed in three moves, writing three ones. The next digit 0/2 is incremented by a four-move local update, followed by 3k clearing moves for k carried digits; digit 1 is incremented by a three-move update and 3(k+1) clearing moves. Both E1 alternatives clear the required triples. The result is the root with the base-four integer increased by one. The omitted high digits are implicit zeros. This finite positive recurrence establishes nonhalting, with total cost 8+6k for even stopping digits and 10+6k for digit 1. Lean proof: Box28Base4.lean.
