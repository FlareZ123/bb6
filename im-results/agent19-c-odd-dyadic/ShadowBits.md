# Compact bit frontier and exact root exclusion

This replaces the cost-word storage in Agent21's DyadicPopulation and the recursive valuation traversal of the older root32 shadow checker by an exact two-kind integer frontier. It is a computational/proof bridge, not a mortality theorem.

For the normalized scalar mass m and numerator x, set b(m)=211 floor(m/2)+108 and N(m,x,d)=x+b(m)+211((m+3d+1) mod 2). Completed node c(m,x) is a genuine positive-cost path at the current accumulated cost n. Pending node p(m,z) is an unfinished last gap of length d>=2 with total intended cost n+1, whose partial quotient z is integral after n bits. The target m already includes the whole intended gap. The following transitions consume one bit:

* c(m,x): if N(m,x,1) is even, emit c(m+4,N(m,x,1)/2); otherwise emit p(m+7,N(m,x,2)/2). Exactly one of these numerators is even.
* Also emit p(m+6,x/2) if n>0 and x is even, extending the last completed gap by two.
* p(m,z): emit c(m,z/2) if z is even; otherwise emit nothing.

The root must not use the last-gap extension at layer zero. There is no need to store words, compute a valuation, evaluate a power of two, or inspect source coordinates in this search. The list semantics permit duplicates; existence rather than multiplicity is what is proved. [ShadowBits.lean](ShadowBits.lean) proves exact membership equivalence (Full or Pending), and the affine transfer from signed OpenAt coordinates, with one additional initial precision bit for mass. [ShadowBitsLift.lean](ShadowBitsLift.lean) establishes that the true source coordinate lift implies the required signed affine equations, and [ShadowBitsExec.lean](ShadowBitsExec.lean) proves that an absorbing-empty tail-recursive evaluator implements the exact frontier. All three compile locally with Lean 4.36.0-rc2, standard axioms only.

[Root32BitsSource.lean](Root32BitsSource.lean) is the checked direct source adapter: use Agent21's reach_open on the literal RunReach, lift the three normalized affine residuals, and contradict the empty frontier at n, provided n+4<=E-17. Original-source CI [45529349945](https://github.com/FlareZ123/bb6/actions/runs/45529349945) compiled all 75 modules and accepted `run_bits_excluded` and `root32_no_highstop_bits` with only propext, Classical.choice and Quot.sound. Unlike a fixed-width modular sieve, one can use the actual root-specific budget E-21 and stop as soon as the frontier empties, without materializing any giant power. The missing universal theorem remains that every authentic j actually empties within that budget. This work is stored in im-results because the new executable formulation and its correctness do not close the unbounded root family.

## No merging and polynomial bit-layer width

[ShadowBitsBounds.lean](ShadowBitsBounds.lean) is locally kernel checked (Lean 4.36.0-rc2, standard axioms only). The positive complete region is preserved, and pending nodes satisfy 0<z and z+844<base(m). Each of the four microstep formulas has a unique parent in this union: the two alternative input types for a completed target have disjoint x intervals, and the two alternative origins of a pending target likewise have disjoint intervals. Hence no deduplication is necessary; every actual list frontier is Nodup. Completed masses lie in [m0+3n,m0+4n]; pending masses lie in [m0+3(n+1),m0+4(n+1)]. A finite grid then bounds the **actual list length** (not just distinct state count) by 2(n+5)base(m0+4(n+1)). The executable frontier uses only polynomially many nodes for any prescribed cutoff n, each with O(log(m0+n)) bits, and a tail-recursive absorbing-empty evaluator. This is a polynomial in the *numeric* parameters m0,n, not in their bit lengths, and does not guarantee extinction or make the full E-21 cutoff practical. It rules out exponential blow-up in the formal search, independent of any random-bit model.
