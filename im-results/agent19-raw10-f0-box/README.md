# Raw10 two-hole residual box: zipper-cycle decomposition

**Status:** intermediate research artifact. The candidate-search script and Lean proof module are committed, but the Lean module has **not yet passed CI**. Do not treat the counts below as an accepted Raw10 parent cover.

## Exact residual box

The selected box is one of the 51 product boxes in the proposed Raw10 parent complement after subtracting the two pinned CTL cylinders and the earlier cycle/halt/side certificates.

Its ten fixed transitions, in A0,A1,B0,B1,C0,C1,D0,D1,E0,E1 order, are:

`1RB0RD_1LC1LB_0LE1RA_0LC0RA_1LF1LD`

The two remaining slots are F0 and F1. The exact residual domains are:

- F0: all 25 transition codes except code 10 (`0RC`) and code 16 (`1RD`), hence 23 choices.
- F1: all 25 transition codes.

Total: (23\cdot25=575) completions.

The two excluded F0 values are already removed by earlier certificates in the 41-box complement: F0=10 is compatible with the existing `cycleTable`, and F0=16 is the final encoded side-witness row. This box is not a whole-parent closure.

## Zipper-cycle candidates

Thus the current split is **490 nonhalting theorem candidates + 28 observed halts + 57 open completions = 575**. The 28 halts are not yet formally certified, so only the 490 nonhalting candidates have proof terms in the Lean source, and even those remain unaccepted until CI compiles the module.

The seven singleton leaves had no `zipCycle` found through entry 2000, period 300, and boundary offsets ±100. The two one-hole leaves did not reach F1 in a 100,000-step bounded trace. Neither observation proves nonhalting or excludes a different certificate.
