# Raw112 F1=0LE residual: recursive counter structure

**Status:** intermediate computational structure, not a nonhalting proof.

## Exact partial machine

The residual is the six-state machine

`1RB0RF_1RC0LB_0RD0LB_1LD1RE_0RA1LC_---0LE`

with the `F0` transition undefined. The current objective is to prove that this partial machine never reaches `F0` on a blank tape; such a theorem would rule out every completion of this leaf.

## Canonical boundary configurations

A repeatable configuration occurs with state `C`, current symbol `0`, left word exactly `1`, and right word

`00 · (110000)^n · S_n`.

Here `n` is the number of six-bit `110000` blocks immediately after the two leading zeroes. The observed trace reaches at least `n=113` within one million transitions. The 100-million-step population scan independently reports continued survival of this residual, but that longer scan is empirical rather than a proof.

## Suffix decomposition

For the observed values `1 ≤ n ≤ 113`, the suffix has the decomposition

`S_n = 001111 · L[n mod 6] · H[floor(n/3)]`.

The six 12-bit low codes are:

| `n mod 6` | `L` |
|---:|---|
| 0 | `110000000000` |
| 1 | `000000111111` |
| 2 | `111110111111` |
| 3 | `110011000001` |
| 4 | `000001111111` |
| 5 | `111111111111` |

`H[k]` is a list of five-bit blocks. In the observed trace, it is constant across the three values `n=3k,3k+1,3k+2`; it is therefore a second counter layer indexed by `k=floor(n/3)`. The first states are:

| `k` | `H[k]` (five-bit blocks) |
|---:|---|
| 0 | ε |
| 1 | `11111` |
| 2 | `00001 11111` |
| 3 | `11100 00001 11111` |
| 4 | `00111 11101 11111` |
| 5 | `11111 11101 11111` |
| 6 | `00000 00110 00001 11111` |
| 7 | `11111 00110 00001 11111` |
| 8 | `00001 11110 00001 11111` |
| 9 | `11100 00011 11111 11111` |
| 10 | `00111 11111 11111 11111` |
| 11 | `11111 11111 11111 11111` |
| 12 | `00000 00000 00000 00001 11111` |

The full trace through the available range is generated by `counter_trace.py`; its CSV output records every `n`, transition count, low code, and high-block sequence. The script also checks that the low code depends only on `n mod 6` and the high-block sequence only on `floor(n/3)`.

## Prefix-rewrite structure

The sequence `H[k]` does not behave like a single affine repetition. Comparing consecutive states and removing their longest common suffix exposes recurring prefix rewrites. Examples observed repeatedly include:

- `[00111] → [11111]` at `k=4→5, 10→11, 16→17, 22→23, 28→29, 34→35`.
- `[00000] → [11111]` at `k=6→7, 12→13, 18→19, 24→25, 30→31, 36→37`.
- `[11100,00001] → [00111,11101]` at `k=3→4, 15→16, 27→28`.
- `[11100,00011] → [00111,11111]` at `k=9→10, 21→22, 33→34`.
- `[11111,00110] → [00001,11110]` at `k=7→8, 19→20, 31→32`.
- `[00001,11110,00001] → [11100,00011,11111]` at `k=8→9, 20→21, 32→33`.

In each line, the unchanged suffix is omitted. These are empirical rewrite observations, not yet a complete rewrite system. The high-block count grows at `k=1,2,3,6,12,18,36` in the observed range. This is consistent with a hierarchical mixed-radix counter (a possible alternating-radix 3/2 structure), but the digit decoder and induction rule remain unknown.

## What did not work

- The one-block `generate_sweeps.py` pump search, extended to late event windows, found no candidate.
- The multi-block `multi_sweep.py` search was extended to 100,000 concrete steps, all boundary groups, up to five repeated blocks of length at most 32, and event gaps up to 16. It returned `NO_MULTI_BLOCK_PUMP` with no candidate decompositions. This is a limitation of that affine-insertion search, not evidence of halting or of nonhalting.

The observed suffix changes are prefix rewrites of a nested counter, not a fixed collection of repeated blocks. The existing affine pump abstraction is therefore too weak for this trace.

## Best next mathematical step

Formalize `H[k]` as a recursively generated stack/counter word over a finite alphabet of five-bit symbols. Infer and prove a total prefix-rewrite operation on that grammar, then prove that the Turing machine's macro transition simulates one rewrite while increasing `n). A Lean proof should establish the macro simulation for arbitrary well-formed counter tails, rather than merely replaying a finite trace.

A promising direction is a mixed-radix counter with alternating radices 3 and 2, but this remains a hypothesis until an explicit decoder and verified transition rules are found.
