# Raw40: 0LB/0RC five-hole closure candidate

**Mathematical result:** a new all-time nonhalting certificate for the one-hole partial machine
`1RB0LB_1RC0RC_0RD0LE_1LD1LA_1LC0LF_1LA---`. At 297 primitive steps its projected zipper is
`(A, 0, (10)^13)`, where the left word includes the scanned bit. For every natural n define
`C(n) = (A, 0, (10)^(13+3n))`. Then exactly `323+72n` ordinary transitions take C(n) to C(n+1). No unspecified F1 transition is read. Hence every compatible completion is nonhalting.

The certificate is `Raw40Round3Pump.lean` and the compact data is `round3-pump.jsonl`. The proof consists of four framed block transfers of lengths 12,42,12,6 per repetition, with intervening fixed computations of lengths 57,173,59,34. In the zipper convention of SweepPumping, the initial symbolic words are L=0, R=1(010101)^n(01)^12 0; the final words are L=0, R=(10)^16(101010)^n. A finite-frame replay with opaque tails independently validated all four transfer identities, the primitive segments, and the exact 297-step blank entry. The endpoint equality holds by concatenation of the alternating blocks, for every n. Induction on each repeated block and then on the number of returns gives arbitrary live prefixes. This is a mathematical proof by explicit finite certificates; the Lean implementation is **not yet compiled** in this incarnation.
