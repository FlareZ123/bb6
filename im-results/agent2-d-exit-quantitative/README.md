# Polynomial right-half first-exit bound for Cryptid D

Agent 2, 2026-11-24. **Original-source Lean 4.36.0-rc2 kernel theorem.** For every live configuration of literal D (1RB0RE_1LC0RA_1LA1LD_1LC1LF_0LC0LB_1LE---), with arbitrary left context and canonical finite scanned-plus-right word w, there is a first physical left exit or halt of positive cost n satisfying

    n <= 189*(2R(w)+8)^3.

Here R(0)=0 and R(w)=R(w/2)+1+2*[w mod 8=6] for w>0, i.e. occupied width plus twice the occurrences of 011. Cost includes the undefined final query (state 6). Before the event the original left context remains an unchanged suffix of the actual stack; head displacement stays in [0,2R(w)+7] and right-word rank <=R(w)+7. A return has displacement -1 and exact written right-word encoding; a halt has nonnegative displacement and state 6.

Exported theorem: Agent2.DExitQuantitative.original_physical_cubic_exit (PolyMain.lean). This replaces the exponential bound on cost while retaining the original linear space guarantees. It is not an all-time rooted classification.

## Mechanism

The seven-bit rank certificate uses class c=w for w<128, else 128+w mod 128. Its 1466 summary rows and 446 active call edges yield a potential V(q,c) in [0,6]. Both children of the exact first-exit recursion strictly decrease H=2R+V+1 for a right-moving call, or H=0 for a terminal/left-moving call. The original source connection and first-event minimality are retained unchanged.

A separate nine-bit outcome-sensitive grammar uses class c=w for w<512 and c=512+w mod 512 otherwise. An outcome row is (input state, input class, output state, output class); output state 6 and dummy class 0 denote halt. Return and terminal productions overapproximate the literal first-exit recursion, including the case where the first child halts. The generated grammar has 5706 return rows, 534 halt rows, and 3241 nonleaf production instances. No binary production has two children in the parent's strongly connected component. There are three cyclic components, of sizes 2,55,21. In reverse condensation order assign each component a degree d and coefficient M, bounding each row's cost by M(H+1)^d. A nonrecursive production needs d >= every child degree and M >= 1 + sum(child coefficients). A recursive production has one child with the same (d,M), and at most one other child of degree < d with coefficient <= M-1. The inequality H^d+H^(d-1) <= (H+1)^d for d>0 completes the recursive case. Maximal d=3, maximal M=189.

PolyArithmetic.lean checks the power and coefficient inequalities. PolySound.lean lifts the finite grammar to every concrete Eval derivation and retains the original physical first-event proof. PolyMain.lean instantiates the checked grammar. The original source and every module compiled locally. The final theorem depends only on [propext, Classical.choice, Quot.sound], no sorry/admit/native_decide.
