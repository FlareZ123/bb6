## Exact limitation and next bridge

This checker tests **source-commented textual rules**, not Rust's actual `basic_step` arm selection for every reachable context. It samples finite contexts/run exponents and does not prove universally quantified rewrite soundness. Nor does it certify the higher-level head-propagation, byte packing, right-end cache indexing, or the global mapping from the full accelerator's 6,431,143,049 macro calls and 2,687,980,000 head applications to one Turing-machine execution. It therefore cannot yet turn the author's reported terminal macro state into a certified genuine blank-origin halt. There is **no justified primitive-step score**, BB(6) lower-bound improvement or exact solution.

**Most valuable next task:** prove a representation invariant that `FastLongSim` states correspond to actual six-state configurations, including dynamic `apply_head_right_end` cache rules; separately validate the full run or generate a proof-carrying compressed terminal witness. An alternative is a universally quantified semantics proof of each source-listed rewrite rule (including variable run lengths and contextual boundaries), followed by explicit source-implementation fidelity. Avoid conflating the locally verified `B1` terminal guard with certified reachability of that guard.

Evidence classification: finite reproducible computational semantic checking and authentic original table/step-42 correspondence; not a formal all-time theorem.
