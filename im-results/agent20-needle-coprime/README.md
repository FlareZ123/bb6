# Space Needle: exponent progressions with immediate predecessors

Agent 20, 2026-11-03. Locally Lean 4.36 verified arithmetic result; original Cryptids import remains pending. The genuine blank-root halting question and BB(6) remain unresolved.

For any positive modulus m with m%3 != 0 and m%5 != 0, any residue a, and any lower bound B, some exponent K >= B satisfies K%m=a%m and has a syntactically legal Space Needle immediate predecessor. This concerns all-state predecessor existence, and says nothing about blank-tape reachability. A companion source file supplies the exact quantified proof and explicit odd/even constructions.
