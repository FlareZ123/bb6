# Two-copy shifted reset-carry product

**Status:** reproducible finite automaton reduction; not an all-time Machine #623 proof.

## Result

The existing three-copy construction in Agent 1's `ShiftedResetCarryDFA.js` tracks suffix offsets 0, 1, and 2 and has 23,099 reachable states. For the S-indexed target window, offset 0 is never selected. The exact window-shift theorem gives
\[
(k'-k,j'-j)\in\{(0,0),(0,1),(1,1)\},
\]
and the source-to-target carry transducer emits the low prefix at indices
\[
k+1,\ldots,k'+1.
\]
Its length is \(1+(k'-k)\in\{1,2\}\). The target word starts at \(k'+2\), so it is exactly the suffix after dropping one or two symbols. Only offsets 1 and 2 are needed.

## Exact product semantics

A state is \((t,c_1,c_2)\), where \(t=\min(2,\text{symbols consumed})\). Copy \(i\) skips the first \(i\) input symbols, then runs the base pair-carry DFA. Its Moore output is null until it has started and otherwise is the base DFA's carry-profile output.

The Mealy mask bit for copy \(i\) is set exactly when that copy's base output changes from null to non-null on the current symbol. The event symbol \(z\in\{0,\ldots,8\}\) recovers the final digit pair of the first reset witness as \((\lfloor z/3\rfloor,z\bmod3)\).

The generator reads:
- `im-results/agent48-623-tight-window/ResetPostStateDFA_BufferRelative.json` — `pair_carry_only`;
- `im-results/agent49-parity623/ResetPostStateDFA.json` — `post_reset_pair`.

The exhaustive check compares both suffix copies against the full `post_reset_pair` DFA on every word of length at most six. For each non-null full output it checks (i) the captured event symbol equals both final previous-pair fields and (ii) the base carry label equals the full left/right carry pair. It also checks event uniqueness and null/non-null agreement.


## Boundary-phase coupling

For \(r=j-3k\in\{-2,-1,0\}\), the same shift set gives
\[
r'=r+(j'-j)-3(k'-k).
\]
The admissible transitions are:
- \((0,0)\): \(r\to r\);
- \((0,1)\): \(-2\to-1\) or \(-1\to0\);
- \((1,1)\): \(0\to-2\).

Therefore copy 2 is selected exactly on the phase wrap \(0\to-2\); copy 1 is selected on every other admissible transition. The separate derivation is recorded in `communications/broadcast/20261120T2345Z_agent24-swindow-boundary-clock.md`.
