# Shifted reset-carry products

**Status:** reproducible finite automaton reductions; not an all-time Machine #623 proof.

**Two exact interfaces are available:**

- **Selected single suffix:** OffsetSelectedResetDFA.js has 351 states and 3,159 transitions. Use it when the current phase edge is known before consuming the stream; offset 2 is selected exactly on \(r=0\to-2\), offset 1 otherwise.
- **Simultaneous suffixes of one supplied stream:** ShiftedResetCarryDFA2.js has 3,101 states and tracks offsets 1 and 2 together. Use it when a downstream product genuinely needs both suffix states of the same input stream. It does not by itself update the reset recognizer across root transitions; the next source-to-target transducer must be composed between windows.

## Simultaneous two-copy product

The existing three-copy construction in Agent 1's `ShiftedResetCarryDFA.js` tracks suffix offsets 0, 1, and 2 and has 23,099 reachable states. For the S-indexed target window, offset 0 is never selected. The exact window-shift theorem gives
\[
(k'-k,j'-j)\in\{(0,0),(0,1),(1,1)\},
\]
and the source-to-target carry transducer emits the low prefix at indices
\[
k+1,\ldots,k'+1.
\]
Its length is \(1+(k'-k)\in\{1,2\}\). The target word starts at \(k'+2\), so it is exactly the suffix after dropping one or two symbols. Only offsets 1 and 2 are needed.

## Exact product semantics

A state is \((t,c_1,c_2)\), where \(t=\min(2,\text{symbols consumed})\). Copy \(i\) skips the first \(i\) input symbols, then runs the base pair-carry DFA. Its Moore output is null until it has started and otherwise is the base DFA's carry-profile output.

The Mealy mask bit for copy \(i\) is set exactly when that copy's base output changes from null to non-null on the current symbol. The event symbol \(z\in\{0,\ldots,8\}\) recovers the final digit pair of the first reset witness as \((\lfloor z/3\rfloor,z\bmod3)\).

The generator reads:
- `im-results/agent48-623-tight-window/ResetPostStateDFA_BufferRelative.json` — `pair_carry_only`;
- `im-results/agent49-parity623/ResetPostStateDFA.json` — `post_reset_pair`.

The exhaustive check compares both suffix copies against the full `post_reset_pair` DFA on every word of length at most six. For each non-null full output it checks (i) the captured event symbol equals both final previous-pair fields and (ii) the base carry label equals the full left/right carry pair. It also checks event uniqueness and null/non-null agreement.

Run from the repository root:

```bash
node im-results/agent24-machine623-shifted-reset-product/ShiftedResetCarryDFA2.js
```

This regenerates the committed `ShiftedResetCarryDFA2.json` beside the script and prints the summary.

## Boundary-phase coupling

For \(r=j-3k\in\{-2,-1,0\}\), the same shift set gives
\[
r'=r+(j'-j)-3(k'-k).
\]
The admissible transitions are:
- \((0,0)\): \(r\to r\);
- \((0,1)\): \(-2\to-1\) or \(-1\to0\);
- \((1,1)\): \(0\to-2\).

Therefore copy 2 is selected exactly on the phase wrap \(0\to-2\); copy 1 is selected on every other admissible transition. The separate derivation is recorded in `communications/broadcast/20261120T2345Z_agent24-swindow-boundary-clock.md`.

## Root-transition adapter

SelectedResetInterface.js exports selectOffset(sourceR,targetR) and classifyTargetWindow(sourceR,targetR,lowOutputs,targetWord). The phase-edge table is:
- -2 -> -2, -1 -> -1, 0 -> 0, -2 -> -1, -1 -> 0: offset 1;
- 0 -> -2: offset 2.

The adapter checks that lowOutputs has exactly the selected length, validates all digit pairs, feeds lowOutputs followed by targetWord through the selected DFA start, and decodes the exact full output label. It returns reset=false if the target window has no reset; otherwise it returns the event symbol, previous pair, base label, full label ID, and complete full label.

For use from the sibling Agent 48 directory:

    const { classifyTargetWindow } =
      require("../agent24-machine623-shifted-reset-product/SelectedResetInterface.js");
    const result = classifyTargetWindow(
      sourceR, targetR, lowOutputs, targetWord
    );

Here lowOutputs is the source-to-target output on k+1 through k'+1, and targetWord is the target digit-pair sequence on [k'+2,j'-2). This adapter is designed to replace a direct full-DFA scan in the finite S-window diagnostic while preserving the exact full label.

## All-state quotient certificate

The base pair-carry DFA is not merely empirically compatible with the full post-reset-pair DFA on short words. The buffer-relative artifact includes a state projection from all 395 full states onto the 349 base states and an output-label projection from all 54 full labels onto the 8 carry labels. The committed OffsetSelectedResetDFA.json records the following exhaustive check:

| Check | Count | Mismatches |
|---|---:|---:|
| Full states with output projection | 395 | 0 |
| Full transitions with state-map commutation | 3,555 | 0 |
| Full output labels in the label map | 54 | 0 |
| Distinct base states hit by the state map | 349 / 349 | 0 |
| Null-to-non-null transitions whose full previous-pair label differs from the input symbol | all such transitions | 0 |

The full post_reset_pair construction records common-reset validation over 225 L start states and 270 R start states, across 8,088 minimal patterns with zero failures. Its initial state 0 maps to base initial state 0. The 351-state adapter retains this initial subset state and the full 349-state quotient (including all no-reset states); the 54 full labels are outputs only. It therefore does not replace the full start-carry rectangles by the post-reset output-label set. The remaining root obligation is to prove that the authentic source-carry rectangle is contained in the start set used by the full automaton.

For every full state \(s\) and digit-pair symbol \(z\), the checked identities are
\[
\pi(\delta_{\rm full}(s,z))=\delta_{\rm base}(\pi(s),z)
\]
and
\[
\lambda_{\rm base}(\pi(s))=
\begin{cases}
\bot,&\lambda_{\rm full}(s)=\bot,\\
\rho(\lambda_{\rm full}(s)),&\text{otherwise},
\end{cases}
\]
where \(\pi\) is the 395-to-349 state map and \(\rho\) is the 54-to-8 output map. On every transition from null output to non-null output, the full output label's L and R previous-pair fields both equal the current input symbol decoded as \((\lfloor z/3\rfloor,z\bmod3)\).

Consequently the base carry label and first-reset event symbol agree with the full post-reset-pair DFA for **every finite input word**, by induction on the word length. Combining this quotient certificate with the exact skip-wrapper semantics proves that the selected-offset machine computes the full DFA's output on suffix \(w[1:]\) or \(w[2:]\) for arbitrary finite \(w\). The separate length-0–6 exhaustive word check remains an independent regression check, not the basis of the all-word claim.

The selected-offset artifact also reconstructs the **full** post-reset-pair output label, not only its carry projection. The 54 full labels have 54 distinct keys consisting of (final previous-pair, left/right carry profile). The JSON therefore contains:
- full_output_lookup[z][baseLabelId] = fullLabelId, where z=3*x+y is the captured first-reset event symbol;
- full_output_labels[fullLabelId], the original complete output label.

All 54 entries are collision-free and present. Thus after the selected wrapper finishes, its base carry output plus captured event symbol decode the exact full post_reset_pair label.

## One-step window extraction

For transition n, the target window W_{n+1} is exactly the suffix of the source-to-target output stream S_n on [k_n+1,j_{n+1}-2) after offset 1+delta_k_n. The boundary clock selects offset 1 or 2. The 351-state selected adapter is the compact interface when the phase edge is known; the 3,101-state product tracks both suffixes for the same stream. The next output stream S_{n+1} is generated by applying the next source-to-target transducer to W_{n+1}; it is not generally a suffix of S_n plus a high symbol. Thus the reset automaton must be composed with that next transducer for a true root-state update. Full scope correction: ShiftedWindowComposition.md.

## Two-step root adapter

ShiftedWindowInterface.js exports classifySuffixAfterTwoPhaseEdges(r0,r1,r2,stream,extensionSymbol). It computes the generic suffix offset \(1+\delta k_0+\delta k_1\), appends the optional extension symbol when the second phase edge has \(\delta j_1=1\), and decodes the full reset label for that suffix. This is only a generic suffix operation; it is not a root-transition adapter. The old classifyNextTargetWindow name remains as a compatibility alias but should not be used to imply a root-window update.

Example:

    const { classifySuffixAfterTwoPhaseEdges } =
      require("../agent24-machine623-shifted-reset-product/ShiftedWindowInterface.js");
    const result = classifySuffixAfterTwoPhaseEdges(
      r0, r1, r2, suppliedStream, optionalExtensionSymbol
    );

Do not interpret optionalExtensionSymbol as the next root transducer's high digit unless that transducer has actually generated it. The next root output stream must be computed by applying the next source-to-target transducer to the current target window before running the reset recognizer.

The generic phase/suffix logic was separately tested against the full DFA on 442,860 cases: all 12 valid three-phase paths, every stream of length 0–4, and either no high extension or each of the nine possible high symbols according to the second edge. There were zero mismatches. See ShiftedWindowComposition.md. This remains finite regression, not a root-transition proof.

The adapter checks the phase edges and rejects any offset other than 1 or 2. It does not certify that sourceToTargetStream or highExtension is authentic, nor that the source carry lies in the full reset rectangles; those remain caller obligations.

## Phase-selected single-copy interface

The two-copy product is useful when the offset is not yet known and both suffix outputs must be maintained simultaneously. In the authentic S-window transition, the boundary phase determines the offset. One can therefore use a single base DFA with two selectable initial states instead of the 3,101-state simultaneous product.

The generator OffsetSelectedResetDFA.js builds exactly this controlled interface:
- 349 original base states;
- one skip1 state that ignores the first output pair;
- one skip2 state that ignores the first two output pairs;
- two selectable initial states, initial_state_by_offset["1"] and initial_state_by_offset["2"];
- 351 total reachable and distinguishable states, with 3,159 transitions.

The stable partition counts are
\[
9,\ 55,\ 163,\ 243,\ 328,\ 351,\ 351.
\]
The script validates both initial-state choices on all 597,871 words of lengths 0–6 against the full post_reset_pair DFA; output/nullness, event-symbol/previous-pair, and carry-label mismatches are all zero.

The wrapper semantics are exact for words of every finite length, not merely the checked prefix lengths. After reading a word \(w\):
- from the offset-1 start, the first symbol moves skip1 to the base initial state, after which every symbol follows the base DFA;
- from the offset-2 start, the first symbol moves skip2 to skip1, the second moves skip1 to the base initial state, and every later symbol follows the base DFA.

Induction on \(|w|\) therefore gives the base-DFA state reached by the suffix \(w[1:]\) or \(w[2:]\), respectively (with the corresponding skip state retained when the word is shorter than the offset). The Moore output is consequently exactly the base carry label on the selected suffix, and the Mealy event bit records its first null-to-non-null transition. The finite length-0–6 check separately validates that this base output/event encoding agrees with the full post-reset-pair labels on all tested words.

For the root-transition consumer, feed exactly the concatenation of the low prefix and target word:
\[
(z_{k+1},\ldots,z_{k'+1})\ \Vert\ (z_{k'+2},\ldots,z_{j'-3}),
\]
i.e. the half-open target interval \([k'+2,j'-2)\). Stop after \(j'-3\); do not append higher digits outside the S-window. The selected start skips only the low prefix and then processes precisely this target interval. When \(j'=j+1\), the newly added high digit is included automatically as the final target symbol.

The root transition selects the initial state from its phase edge:
- choose offset 2 exactly for \(r=0\to-2\);
- choose offset 1 for every other admissible phase edge.

Run from the repository root:

    node im-results/agent24-machine623-shifted-reset-product/OffsetSelectedResetDFA.js

The generated automaton is committed at im-results/agent24-machine623-shifted-reset-product/OffsetSelectedResetDFA.json; running the script regenerates it. It is the smaller integration interface when the boundary phase edge is already known. It does not replace the 3,101-state simultaneous product when both offsets are required at once.

A plausible next finite composition is the branch-specific source carry/previous-pair digit transducer (225 L states or 270 R states) crossed with the 351-state selected-offset reset DFA. This gives at most 78,975 L states or 94,770 R states before reachability reduction. Each source pair updates the carry transducer, its emitted pair advances the reset DFA, and the phase edge fixes skip1/skip2. This is a proposed architecture only; it has not been built or shown closed.

## Scope

It does not close the weighted-drain/root-language transition system, establish a Machine #623 halting decision, or solve BB(6). Keep this artifact in `im-results/`.
