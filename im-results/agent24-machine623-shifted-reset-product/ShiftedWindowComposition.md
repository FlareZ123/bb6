# One-step S-window extraction and shifted reset recognition

**Status:** exact index relation for one source-to-target transition, plus finite automaton verification. It is not a two-step root-state update theorem.

Let \((k_n,j_n)\) be the S-window indices at root state \(n\), and write
\[
\delta k_n=k_{n+1}-k_n,\qquad
\delta j_n=j_{n+1}-j_n.
\]
The established shift set is
\[
(\delta k_n,\delta j_n)\in\{(0,0),(0,1),(1,1)\}.
\]
For transition \(n\), let \(S_n\) be the source-to-target transducer's output digit-pair stream on indices
\[
[k_n+1,j_{n+1}-2),
\]
i.e. the symbols \(k_n+1,\ldots,j_{n+1}-3\). The target window at state \(n+1\) begins at \(k_{n+1}+2\), so it is exactly the suffix
\[
W_{n+1}=S_n[1+\delta k_n:].
\]
The boundary clock \(r_n=j_n-3k_n\in\{-2,-1,0\}\) determines the offset: \(\delta k_n=1\) exactly on \(r_n=0\to r_{n+1}=-2\); otherwise \(\delta k_n=0\). Thus the current target window is always suffix offset 1 or 2 of the current transition's output stream.

The 351-state selected-offset adapter is the compact interface when this phase edge is known. The 3,101-state simultaneous two-copy product tracks both offset-1 and offset-2 suffix recognizer states for the same stream. Both are exact finite automata for the current target window and preserve the full post_reset_pair output label through the all-state quotient certificate.

## Important scope correction: no output-to-output suffix identity

The next transition's source is the current target state. Its source digit window is therefore drawn from \(W_{n+1}\), but the next target window \(W_{n+2}\) is produced by applying the next source-to-target digit transducer to that source window (with its own carry seed and corrections). In general, the next output stream \(S_{n+1}\) is **not** just a suffix of \(S_n\) plus a high digit. The optional high digit is generated by the next transducer; it is not an extension that can be appended to the previous output stream to obtain the next output stream.

Consequently the earlier proposed identity
\[
W_{n+2}=S_n[1+\delta k_n+\delta k_{n+1}:]\Vert h_{n+1}
\]
is not established and must not be used as a root-transition update. It conflates the next source/input window with the next transducer's output window. The correct composition is:
1. extract \(W_{n+1}\) as suffix offset \(1+\delta k_n\) of \(S_n\);
2. apply the next source-to-target transducer to \(W_{n+1}\), with the authentic next carry seed, to generate \(S_{n+1}\);
3. classify \(W_{n+2}\) as suffix offset \(1+\delta k_{n+1}\) of \(S_{n+1}\).

The reset DFA/product must therefore be composed with the next digit transducer to obtain a true root-state update. The 3,101-state product remains a useful recognizer component, but alone it does not perform that transducer composition.

## Finite regression

The phase-selection/high-extension helper was tested as a generic suffix operation against the full post_reset_pair DFA: all 12 valid three-phase paths, all streams of lengths 0 through 4, and (according to the second edge) either no extension or each of the nine possible appended symbols. This gives 450,241 cases with zero mismatches. This only validates the generic suffix/product mechanics; it does not validate an output-to-output root update or authentic transducer composition.
