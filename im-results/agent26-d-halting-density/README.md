Thus any certified pure-unary halting family transfers to every finite suffix with unchanged cardinality. ## Quantitative regular-language obstruction (all four roots)

`automata.tar.xz.b64` contains six new Lean modules plus a deterministic source generator (archive SHA256 `39907f2e66b5f8145683a04076901d1e998762dd06fa44f4ead0707c90ab25c4`). NFA proof pumps a single accepting path, with no determinization. `UnboundedRegular.lean` and `NfaUnbounded.lean` show that unbounded certified walks from n≥5 exclude all finite regular-language inductive safe invariants (even with transient exceptions). `GenerateRoot.lean` generates kernel-checkable 32-return chunks for each of 5,9,15,39, splitting a 1,024-return source-certified walk into 544+480. `RootNfaBounds.lean` composes these to `four_root_nfa_bound`: every globally safe inductive regular-language certificate containing any one of the four seed sections requires at least **3^481 ≈ 3.1284e229 states**, for an NFA as well as DFA, in the encoding that reads the unary block then the finite suffix. The initial seed sections are those of Agent19's physical bridges. This is a complexity lower bound on a class of proof methods, not a root decision or an unconditional impossibility of all nonhalting proof techniques.

## Complete return cylinders and exponential bounded-survival cover

`holes.tar.xz.b64` (decoded archive SHA256 `31ec65c1d8a6571ad12f828d50d1e96c360a5c6be0d23c18aa39f94aad4bf027`) contains WalkHoles, CylinderHoles, FullCylinderHoles, BoundedSurvival. Compile in that order after DRouteDensity and the sibling affine-repetitions CycleSource. `cw_lower` and `cw_cylinder` prove every fixed valid mixed A/E/B word of L returns has exactly one input class mod 3^L for all unary inputs ≥2, even smaller than the original witnessed input. `cw_output_mod` proves equal inputs mod 3^(L+d) have outputs equal mod 3^d for the same certificate word. `full_cylinder_holes` proves each certified prefix's residue cylinder has T=1,057,916,215,296 distinct completely halting subcylinders mod 3^(L+108+zeros(false::w)), where w is its final suffix in sect notation. Thus the result applies to all positive representatives ≥2, not just upward perturbations. `children_bound` excludes ≥T among 3^D children whenever D≥108+zeros(false::w). `cover_contains`, `cover_bound` prove that for any candidate set G of nonhalting prepared inputs (fixed initial suffix v) admitting t*D certified returns to suffixes satisfying 108+zeros(false::w)≤D for every t, its residue cover mod 3^(tD) has ≤(3^D−T)^t classes. Consequently its upper natural density is zero: the fraction in the periodic cover tends to zero geometrically as t→∞. This is conditional on bounded complexity at all selected block boundaries, and a density statement cannot decide an individual blank-derived input. All four modules checked locally with Lean 4.36.0-rc2, final axioms only [propext, Classical.choice, Quot.sound].
