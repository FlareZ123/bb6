# Edge-aligned product plan for the #623 S-window

**Status:** research plan, not a proof or a closed product.

## 1. Keep the phase notions separate

For each authentic root transition D_n -> D_(n+1), define an edge record E_n by joining:

1. **Agent 48 source-to-target phase** for D_n -> D_(n+1), from `im-results/agent48-623-tight-window/s_window_boundary_phases.js`. This is an edge quantity; the finite replay has 1,318 distinct phase keys.
2. **Agent 1 target own-start phase** for D_(n+1), from `im-results/agent1-623-swindow-obstruction-product/analyze_exact_seed_product.js`. This is a state quantity; the conservative replay has 697 keys.
3. The target window's exact reset seed, exact final 66-state carry, 211-state universal residual subset, reset event/witness information, and rolling buffer.
4. The authentic low/high boundary shift and high-extension symbol.

Join by target index n+1. Do not identify the 1,318 edge phases with the 697 own-start phases, or pair D_n's own phase with D_(n+1)'s subset.

The valid boundary shifts are (k'-k,j'-j) in {(0,0),(0,1),(1,1)}. The next word is generated by applying the next source-to-target transducer to W_(n+1). It is not obtained by appending a high digit to the previous output word.

## 2. Distinguish the two window diagnostics

- **Conservative envelope:** B_S=max(34 ell_S+140,36 ell_S+88). Agent 1 independently reproduces 81 universal-subset exceptions on target windows D34..D10001. With same-state alignment D33..D10000, the exact-seed product has 82 exceptions. These are valid conservative diagnostics.
- **Correction-only candidate:** B_corr=34 ell_S+122. SWindowPostResetSynchronization.md reports 84 candidate non-rank-one suffixes. Preserve all 84 as explicit states, but keep this sharper scan separate until the source-correction bridge is pinned/compiled. Do not silently substitute 81/82 for 84 or vice versa.

The 211-state subset is the image of all 66 possible post-reset seeds. Rank>1 means not universally synchronizing; it does not mean the authentic root carry is unknown. The 736-state reset-output DFA identifies the actual seed; the 66-state closure then gives the exact actual end state.
