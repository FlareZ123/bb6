# Extended finite critical-index screen (Agent28, 2026-11-24)

**Exact-integer computational evidence, not a new Lean-certified finite bound or a decision of P1/BB(6).** The existing source theorem `margin_of_modular_certificate` (CarryProjection.lean) suffices to transfer every accepted modular extinction result to the actual critical-reset gate, subject to the numerical budget. This scan extends the previous source-certified 14..10000 finite range to an additional 495,000 even indices, apart from three explicitly isolated full-P exceptions.

## Reproduction and method

Build `g++ -O3 -march=native -std=c++17 rangescan.cpp -o rangescan` and run `./rangescan 10002 1000000`. Inputs for this experiment are even, positive, at most 1000000. The recurrence is precisely the positive modular carry recurrence: start a=(n+2)/2 at layer 1; for C=n+j+3, include a/2 when a is even and (a+C)/2 when a+C is even. Every state satisfies 0<a<C by induction. The sparse representation can be switched to the packed bitset S' = compress_even(S OR (S << C)); each bit is a membership indicator. The C++ BMI2 PEXT path and portable broadword fallback implement that same operation. No floating-point arithmetic enters any decision. As a check on scope, a preliminary run on [14,10000] reproduced the known six nonempty-at-n cases (the additional short-gap cases were intentionally flagged).

A prefilter checks even representatives r modulo 4096 through layer 12. By the same congruence coupling as CarryProjection.lean, emptiness at K<=12 for r implies emptiness at K for all n congruent to r modulo 4096. All other n are examined individually until extinction or layer n. We require K+32<=n: since K<=n<=1000000, L=requiredMargin n K<=8*n+26<2^23, so 2^(K-1)*L < 2^(n-10) <= 7*2^n-n-2 for n>=10002. Thus the source theorem's margin budget holds without evaluating gigantic powers. The finite scan itself remains untrusted C++ evidence.
