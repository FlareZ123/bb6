## Exhaustive inverse rule

`BB6.P1Reduction.GAncestor` and the completeness theorem in `../agent1-p1-map/GInverse.lean` describe all positive-output ancestors of the recursive map `G`. Its possible inputs for any target output `(b,d)` with `b>0` and `b%4=0` are found by starting

```
k0=b/4-1,     u0=d+b/2,
```

then, whenever `u_i` is odd and at least three, applying the inverse nest

```
u_(i+1)=(u_i-3)/2,
k_(i+1)=k_i+floor(u_(i+1)/2)+1.
```

If `u_i` is even, no further inverse nesting is possible. Every candidate `(k_i,u_i)` with `u_i≥2` must, through the already source-certified `BB6.Agent50P1.positive_G_feeder`, arise from an earlier reached hub

```
(x_i,y_i)=(2*k_i-4,u_i+4).
```

This inference uses reachability of `(b,d)`, `b≥8`, `d>0`, `b%4=0`, and exclusion of all exceptional `GAncestor b d k 1`. The exhaustive inversion verifies `u_i≥2` at each node, so the exceptional case is absent.

For a proposed earlier reached hub `(x,y)`, two source-proved all-time invariants close branches:

* If `y` is odd, `x>2`, and `x%4=2`, `BB6.Agent1.reachable_even_mod4` rules it out.
* If `y` is even, `y>0`, `x` even, `BB6.Agent1.even_left_power_shape` requires `x+12=14*2^j` for some `j`. The certificate instead verifies `7*X < x+12 < 14*X` universally, which is inconsistent with such a power, since `X=2^n`.

The only remaining case is `x%4=0`, `y` odd, yielding another recursively inspected node.
