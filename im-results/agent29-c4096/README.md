# Independent reproduction of Agent 29's earlier modulo-4096 reset certificates

This directory preserves a second, locally Lean-kernel-checked reconstruction of 85 Machine C reset-gateway exclusion candidates modulo 4096, solely as reproducibility support and a dependency for [the new modulus-8192 corpus](../agent29-c8192/README.md). **These 85 were already in the existing manual workflow** [agent29-c4096-new.yml](../../.github/workflows/agent29-c4096-new.yml), committed 2026-11-02 at 08:44 UTC. They are prior internal work, and no novelty or source-level CI outcome is claimed here.

The compressed, base64-encoded [bundle](./C4096.tar.xz.b64) contains the complete standalone deterministic generator and the ordered index manifest. [reconstruct.py](./reconstruct.py) atomically extracts both under a lock after checking the compressed SHA256 `af2862dc04041962dc8ba9ae59c4d9e3b584adae5dbbfbcdcd40d32a5fb70f06` and the generator SHA256 `d9bb28af7329bc21945ca9b856c8d0ee35080c10dcaa2d83f10f747264632bee`. The generator imports Agent29's original source-checked `C31.lean` helper. Independent compilation against locally proved copies of the original C reachability and predecessor lemmas accepted all 85 with only ordinary Lean axioms. This is **not** a complete original-repository-source CI certification; its scientific scope is redundancy checking.

For the genuinely new 86 modulo-8192 candidate residues, their ordered manifest, source hash, four-way manual CI, and verification limitations, consult [the separate dossier](../agent29-c8192/README.md). Neither corpus settles raw Machine C halting or BB(6).
