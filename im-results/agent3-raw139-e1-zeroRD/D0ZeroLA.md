## Shared mathematical obstruction resolved in a ray model

Extra leaves 210,251,657 are respectively `[7,12,11,14,14,5,0,16,20,13,24,13]`, `[7,12,11,14,14,5,0,16,20,13,24,7]`, `[7,12,11,14,14,5,0,16,22,13,24,15]`. All have exactly F0 absent. [CounterCarryBridge.lean](CounterCarryBridge.lean) transfers exact table identity and every successful step to original physical semantics; source gate pending at writing.

Use physical word notation L A 00 R, with all undisplayed tails arbitrary. The main theorem is that for every k, all three machines have a positive finite run
`L A 00 (10)^k 0 R -> L A 00 (00)^k 1 R`.
For k=0 direct 6 moves. For k+1, A00 moves to C after writing 11; C scans (10) pairs into (01) on the left. C0 turn via D1,E0,F1 returns A at the final pending left pair, with right 0011R (possibly via the six-move increment). The left suffix in physical order is 1(10)^k. A scan of (10)^n11, followed by the B1/D0 branch, reaches A1; repeated A1,D0 removes all n pairs, replacing them by 00 on the right. If preceding left is 1, the A1,D1,E1,D0 rule consumes the last 1 and returns to the original anchor. If preceding left is 10, the E0,F1 branch consumes that pair, with n+1 low digits reset to zero (except first low digit one in variant 251), followed by terminal 01R. Fill those n+1 digits and increment terminal 01 to 11 using only already proved carry lengths <= n+1. This reduces pending left pairs by one and increases n by one. Starting with n=0, k pending pairs, every recursive carry length is <=k. Thus strong induction (implemented as through-k induction) proves the k+1 case. Starting from blank, encode the ordinary finite little-endian binary word as pairs b0 after A00; repeated increment gives positive-time prefixes of arbitrary length. F0 is never queried. No finite-run assumption is used.
