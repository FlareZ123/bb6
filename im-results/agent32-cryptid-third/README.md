Write `I_n(y)` for state F scanning a zero, with an all-zero left half-line and tape immediately right of the head `1^n y 0^infinity`. Agent 31's `CryptidBoundary.init(xs)` is `I_2(xs)`.

The formal Lean theorem `CryptidBoundary.full_E_00` states, for **every** `k : Nat` and **every** `ys : List Bool`:

```lean
run (12*k*k+49*k+50)
  (init (List.replicate (3*k+2) true ++ false::false::ys)) =
  ⟨[], false, List.replicate (8*k+5) true ++
    (false :: List.replicate 6 true ++ ys), 5⟩
```

In compact mathematical notation:

```text
I_(3k+4)(00 ys) --[12k²+49k+50 primitive steps]--> I_(8k+5)(0 1^6 ys)
```

The arbitrary suffix `ys` is preserved verbatim. The return carries a new fixed six-one packet following a zero delimiter, so this branch is structurally distinct from the neighboring one-symbol and two-zero complete returns.
