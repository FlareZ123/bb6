# Counted affine-block replay

**Status:** locally kernel-checked general clock arithmetic and a generic recursive evaluator, conditional on a source-sound leaf oracle. The original D-specific instantiation remains the next proof obligation. No root decision follows.

For an L-event path, record its exact primitive clock as P(q)=c+bq+aq² when the starting unary parameter is lifted by 3^L q. The endpoint of a completed L-return path lifts by 8^L q. For consecutive lengths i,j, the clock is P(3^j q)+R(8^i q), with coefficient-wise nonnegative arithmetic. Shifting a representative by q changes the constant to P(q) and the linear coefficient to b+2aq. For one event with clock 12k²+bk+c, the leading coefficient for a k-lift is 12. The universal quadratic coefficient for L events satisfies Q_0=0, Q_(L+1)=9Q_L+12·64^L and 55Q_L+12·9^L=12·64^L. These identities are checked in CountedBlocks.lean.

CountedReplay.lean proves Sound for every positive binary Plan using source composition and a uniform one-event oracle. An incomplete block of d events lifts by 3^(L-d)q in the clock variable. A terminal event counts as one event for clock scaling, but is not a return. The evaluator handles open leaves without claiming a decision, and its output supplies the exact clock of the proved prefix or terminal. The representative n−3^L·(n/3^L−1) is at least 2 for n≥2. It avoids full-size arithmetic at every individual event. Local Lean v4.36.0-rc2 compiled both modules; axioms propext and Quot.sound only.

The included independent numerical implementation count_blocks.py compares the block clock with direct arithmetic on the four roots and with literal raw-machine first-event simulation on 1,500 deterministic randomized cases, including 6 halts. A 65,536-return model run from each root completed without encountering halt or open. The clock bit lengths including root offsets (5,9,15,39) are 185476,185477,185478,185481. Full endpoint and clock SHA256 hashes and axiom logs are in the archive. These checks are not kernel evaluations of those trajectories.

## Reproduction
Decode counted-blocks.tar.xz.b64 and check SHA256 f789c7348e3b3e0a4a014c475b7d05ed92911c7e9da3ba568ff7bdc6beda9c7c. Extract, use Lean 4.36.0-rc2, compile CountedBlocks.lean to CountedBlocks.olean and then CountedReplay.lean with LEAN_PATH set to the extraction directory. Run the Python script with its documented CLI. The existing source certificates in RouteAllFront should supply the leaf oracle; the source adapter and four-root terminal transfer remain to be proved. Frozen sink versus last defined transition is a distinct convention and must be handled explicitly.
