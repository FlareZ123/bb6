# Exact linear-time discovery of oriented side cycles

Status: new candidate-generation algorithm and locally kernel-checked rotation theorem; Raw42 integration in progress. No claim of priority in the wider literature.

Existing side-cycle soundness allows a fixed retained half-line whose boundary can be anywhere. **Rotation theorem:** any positive period n with nonnegative oriented displacement and a valid retained-side trace admits a rotation j<n with the same displacement and period, where the retained boundary is exactly the rotated entry head. Choose an oriented extremum among queried heads. Transfer the first j steps along the original TailRel. The remaining trace before the old endpoint stays on the extremal side; its wrapped part is the original prefix shifted by the oriented displacement. Thus its entire period stays on the new side, and the old TailRel restricts to this new boundary. The detection endpoint occurs no later than original entry + 2n-1. Lean theorem BB6Coverage.Agent32SideRotation.rotate_sideCycle proves this over the authentic semantics. Local Lean 4.36.0-rc2 check against Raw59 artifact 15054146521: only propext, Classical.choice, Quot.sound.

## Exact scanner

side_scan.hpp maintains the left and right semi-infinite binary words as canonical interned cons IDs, omitting trailing blank zeros. ID 0 is the infinite zero word. For each tail ID and bit, at most one cons ID exists. It therefore compares complete half-lines in O(1) by exact ID equality, not a hash or finite window. Each side keeps a monotone stack of previous entries. A right entry remains active precisely until the head crosses strictly left of its entry head; left entries are symmetric. The per-word per-state last-index array points to the newest still-active entry, restoring the previous index on each pop. A repeated state and word at an active entry is a side-cycle witness with boundary equal to that entry head. At most a constant number of nodes and records are inserted per step, and each record is popped once. O(t) time and O(t) memory for t simulated moves (amortized vector growth, no probabilistic dictionary). Rotation proves that arbitrary-boundary side cycles will be discovered after at most one additional period if no earlier witness appears.

Candidate certificates remain untrusted and must pass the existing exact Lean cycle checker; finite search failure is never a halting or nonhalting assertion. The scanner handles sparse tables and stops immediately on a genuine first hole. The normalizing first-hole enumerator is in enumerate_tnf.cpp; it branches over each introduced state and the least fresh label only, accounts for raw multiplicity 6-cut at introduction, and retains all open leaves. PartialCut.lean proves the literal and normalized partial-cut composition using the existing zipper audit and tnf_branch_sound. It was locally kernel checked against the same Raw59 artifact, with standard axiom profiles.
