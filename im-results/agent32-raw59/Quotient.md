# Deterministic quotient certificates for Raw59

Let a sparse n-gram witness have reachable relation S(q,a,x,y) and left/right observed stack-edge sets. A width-w pop edge (x,e) determines a partial deterministic push from (floor(x/2)+e·2^(w−1), x mod 2) to x. Include zero and all state and edge endpoints. Classify x by its exact profile {(q,a,y): S(q,a,x,y)} on the left, and y by {(q,a,x): S(q,a,x,y)} on the right. Refine both partitions to a fixed point for the two partial push maps, treating missing transitions as a distinct value. Number zero's class first.

**Preservation argument.** Project the witnessed relation and edges to the quotient. At a projected live configuration choose representatives x,y in S. The receiving-side push is defined by the original closure and its quotient target is independent of the representative. For a sending-side pop edge projected from another representative of y, equality of exact profiles allows that representative to replace y while preserving the live relation with x. The corresponding original pop, push and successor are certified by the old closure, hence their projections satisfy the new closure. The same argument with sides exchanged handles a left move. The projected blank is included. Unused push entries may be filled arbitrarily since every push at a witnessed configuration is defined. Consequently the projected relation gives a finite nonhalting invariant. This is a mathematical construction argument, not a new Lean theorem asserting transformation of arbitrary source certificates.

quotient_search.py tries cheaper language, state-symbol and partner-profile partitions before exact-profile refinement. Each candidate is independently saturated from the actual blank root. fold.py makes deterministic congruence folds on observed partial push tables and resaturates; a fold is accepted only if it stays closed and does not increase the reachable relation size. Seed and attempt budget are fixed. emit_quotient.py emits existing FastBiDFA certificates with the exact partial table and 12 state-symbol row checks. Smaller certificates combine rows in one module; larger ones split by row. Every row uses kernel reduction, followed by the original FastBiDFA.never theorem. Neither search nor folding is trusted by Lean.

## Measured pilot

For exact Raw59/0LB/113, table 1RB0LB_1RC0LB_0RD0RF_1LD1RE_0RA1LA_---0LA, the original 14/20-window witness has 33111 live configurations. The exact-profile quotient has 3427, the best partner-profile quotient 3425, and seeded folding gives 1649 configurations, 296 edges, and 93/147 stack states. All 12 rows and the final original-semantics NeverHalts theorem compiled locally using FastBiDFA and original checked 0LE dependencies. Separate-row build took about 28 seconds (largest row peak 1.48 GB); combined-row proof took 25.95 seconds (peak 1501172 KiB). The synchronous trie-routing pilot also passed all rows, but needed about 3.5 minutes and substantially more memory.

All 128 n-gram candidates in the five pending upgrade branches independently saturated after initial quotienting: 898819 original configurations to 199952, before folding. Per-branch (original → quotient): 0LA 177271→46595; 0LB 263049→56745; 0LF 318607→72722; 1LB 54737→17061; 1LE 85155→6829. These are candidate sizes, not counts of accepted parent machines.

The existing upgrade_data.py generator uses this route for 0LA, 0LB, 0LF, 1LB and 1LE, after checking the original enumeration digest and n-gram witness manifest. It skips previously covered tables, uses seeded folding budgets, and emits the same named table/never interface. Regenerated quotient_witnesses.json records the explicit automata. The checked 0LE and 1LF artifacts remain unchanged.

ClosedBase is split into six disjoint groups; parent_shards.json lists exact roots. The final parent composition still checks every child, original source identities, axiom profiles, and the unchanged parent bound. UpgradeRemaining stops at the stable Raw59 parent theorem rather than rebuilding the superseded canonical77 roster. No canonical-roster or BB(6) verdict is claimed here.
