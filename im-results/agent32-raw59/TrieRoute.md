## Soundness theorem

[TrieRoute.lean](TrieRoute.lean) imports the original AsymNGram proof model. A route consumes the source key bits low-to-high, selectively copies them to the edge and target tries, and inserts or discards the bits specified by a Turing-machine transition. For each live source row it separately checks both push far-bit choices and the four pop-head/extension choices. It tests the source row width, rejects states at unassigned or halt transitions, and requires a destination only when the pop extension is in the allowed edge set. The `routeRow_sound` theorem implies the exact old `Trie.all stateStepOK` obligation, without repeating that computation. `route_check_of_rows` supplies the unchanged `AsymNGram.never` theorem. All these generic proofs compiled locally with Lean 4.36.0-rc2 against the original accepted 0LE artifact 15054146521; printed axioms are only propext, Classical.choice, Quot.sound.
