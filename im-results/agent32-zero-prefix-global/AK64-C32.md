# Machine C: experimental mixed A/K64–C32 quotient

**Status: reproducible computational candidate; not yet Lean-kernel checked.** This is an intermediate result, not a Machine C classification and not a BB(6) bound.

## Quotient

For the original Agent 11 accelerator BB6CLine.nextC from blank-entry state (5,0,1), use three coordinate maps:

- qA(x)=x for x<2, otherwise 2+(x-2) mod64;
- qK(x)=x for x<2, otherwise 2+(x-2) mod64;
- qC(x)=x for x<4, otherwise 4+(x-4) mod32.

For an abstract coordinate u, enumerate its single representative u below the corresponding base, and both u and u+modulus otherwise. The abstract state space has dimensions 66 × 66 × 36 = 156,816.

The thresholds preserve the exact branch tests:
- A: a=0 and a=1;
- K: k=0 and parity of k;
- C: c=0,1,2,3.

The moduli preserve the affine outputs. Adding 64 to A or K preserves all A/K branch conditions and changes the relevant outputs by multiples of 64; adding 32 to C preserves the C branch conditions and changes C outputs by multiples of 32. For C representatives near the boundary (e.g. c=4,5,6), both the lower representative and its +32 lift are explicitly enumerated, so transitions that cross below 4 are not lost.

## Reproducible closure

Run:

```sh
node im-results/agent32-zero-prefix-global/ak64c32_check.js
```

The script implements the exact nine CLine clauses and enumerates every representative transition. Two independent implementations were run during this investigation (typed-array BFS with the repository-style encoding, and Set/array BFS with a different encoding); both returned the same census:

| Quantity | Value |
|---|---:|
| Abstract vertices | 156,816 |
| Reachable abstract vertices | 77,020 |
| Representative edges | 576,340 |

The script also checks the full residue scans and the three target cells below.

## New gate exclusions suggested by the quotient

The quotient does not contain the following abstract states:

| CLine gate | Raw state | Abstract state |
|---|---|---|
| Reset, j=58 | (117,178,0) | (53,50,0) |
| Reset, j=59 | (119,181,0) | (55,53,0) |
| Side, n=16 | (0,64,407) | (0,64,23) |

If the quotient closure and source bridge are kernel-checked, these cells yield the all-time exclusions:

- not Reach (2*j+1,3*j+4,0) for j congruent to 58 or 59 modulo 64;
- not Reach (0,4*n,24*n+23) for n congruent to 0 modulo 16.

The latter family is additional to Agent 11's existing exclusion of odd side indices. The reset classes are additional to the old M32 exclusions: M32 admits j=58,59, while this mixed quotient excludes them.

The mixed quotient's full scans are:
- reset indices modulo 64 admitted: 0,2,6,8,10,11,14,15,18,23,24,26,27,30,31,32,34,38,39,40,42,43,46,47,50,55,56,62,63;
- side indices modulo 32 admitted: 2,3,4,6,7,8,10,11,12,14,15,18,19,20,22,23,24,26,27,28,30,31.

The M32 and mixed quotients are distinct over-approximations. A reachable source state must be admitted by both; intersecting their reset-admitted residue sets gives the full B8/M64 reset-admitted set found in the larger quotient.

## Formalization target and limitations

This is not yet a proof. The next step is a Lean certificate for the 156,816-state closure and a source bridge to the original BB6CLine.Reach. The quotient is smaller than the full B8/M64 quotient (373,248 vertices, 1,182,347 representative edges) and therefore is the preferred formalization target.

Do not infer Machine C nonhalting from these three excluded families. The exact stops_iff_reset_or_side criterion still has other reset classes and side classes; this quotient leaves many of them admitted. No claim is made that any admitted quotient state is genuinely reachable.
