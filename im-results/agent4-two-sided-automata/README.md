# Two-sided finite stack-relation nonhalting certificates

A certificate consists of two finite stack relations and a finite set of joint abstract configurations. Each stack relation has a distinguished empty-stack state 0 and a blank self-loop. A concrete word is related to a state iff its bits can be consumed via inverse push edges to state 0, with every intermediate state in bounds. The invariant records a pair of stack witnesses and the scanned bit and machine state. A verified move must have a legal push edge and every possible pop edge must give a listed successor. Existential witnesses are maintained inductively; no determinism, totality of the discovery automaton, or correctness of its descriptors is assumed.

TwoSidedAutomata.lean proves this preservation and arbitrary finite live prefixes. The general theorem through live passed Lean 4.36.0-rc2 locally against exact copied zipper and trie definitions (standard propext, Classical.choice, Quot.sound); the original-source never bridge and concrete certificate checks are pending CI. Search uses lazily allocated run-length descriptors with saturated or cyclic length classes; newly learned push edges wake every dependent abstract pop. This is untrusted candidate generation, not a new trusted model.

Raw58 parameters in rle-params.json cover 19 previously unclassified open leaves in the pinned raw58 census; LE203 has 8,723 abstract configurations and 87/348 stack states. The other 18 include several compact cases under 1,000 configurations. The emitted exact Boolean checker is decisive. No global roster reduction follows merely from discovery. This certificate format also supports remapping sparse wide n-gram certificates to finite stack relations.
