## Compatibility audit after inspecting one upstream proof module

The upstream proof source is not a drop-in import against the archived
pin. The current upstream main toolchain is
\`leanprover/lean4:v4.35.0-rc4\`, whereas the local BB6 task requires
Lean 4.36.0-rc2. More importantly, a blob comparison of
\`BusyBeaver/Basic.lean\` and \`BusyBeaver/Bridge.lean\` between the
pinned commit and upstream main shows API differences:

- Current main adds reachability aliases including
  \`stepStar_trans\`, \`stepPlus_stepStar\`, and \`stepPlus_trans\`;
  these are used by the inspected NonHalt proof module and are absent
  from the pinned Basic file.
- Current main's Bridge parser accepts the \`HHH\` halt marker in RLE
  strings. The pinned Bridge parser only accepts \`---\`.
- The proof modules use \`load_rle_machine%\` with \`HHH\` in the
  machine string.

This does not make transfer impossible. It means a source-vendoring
route must normalize \`HHH\` to \`---\` and supply the missing Basic
aliases (or prove that the relevant source proof can be rewritten using
the pinned API). A separate scratch project on upstream main is another
route, but its native Lean toolchain is 4.35.0-rc4 and must not be
mistaken for the required local RC2 acceptance.

An inspected representative module,
\`BusyBeaver/BB6/NonHalt/M_1RB0LC_1LC0RB_0LE0LD_1LCHHH_0RA1LF_1LA1LF.lean\`,
imports only \`BusyBeaver.Basic\` and \`BusyBeaver.Bridge\`, defines its
machine with \`load_rle_machine%\`, and exports
\`is_not_halt : IsNotHalt target\`. The generic local adapters should
handle the semantic transfer once the source proof module itself is
available and compiles.

A further tree check at the pinned commit confirms that
\`BusyBeaver/Calculi/HaltShared.lean\` and
\`BusyBeaver/Calculi/Counter.lean\` are also absent. The smallest exact
halt-overlap module (14,222 bytes),
\`BusyBeaver/BB6/Halt/M_1RB0RE_1RC0RA_0LD0LB_0LA1LE_1LC1LF_0LAHHH.lean\`,
imports \`BusyBeaver.Bridge\` and \`BusyBeaver.Calculi.HaltShared\`.
The smallest exact nonhalt-overlap module imports
\`BusyBeaver.Calculi.Counter\` and another NonHalt proof module.
This makes direct vendoring against the old pin more involved than
adding only the three Basic aliases and HHH parser. A separate scratch
project pinned to upstream main is the cleaner first experiment.

The other halting overlaps use different engines: F424/F412 use `SymRunEngine` and are analyzed separately in [SymRunCost.md](SymRunCost.md); F067 uses a `TowerA3`/phase engine. Only the two F289 rows share the RLE-stack cost semantics discussed above.
