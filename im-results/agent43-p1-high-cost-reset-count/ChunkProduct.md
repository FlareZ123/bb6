# Word-local certificates for delayed-prefix margins

The earlier RunMarginFast proof uses an integer containing the entire low product. The concrete candidate words from the large packed searches can be hundreds of millions of bits, so evaluating that integer inside the Lean kernel is not a viable certificate strategy.

[ChunkProduct.lean](ChunkProduct.lean) supplies a kernel-checked word-local arithmetic layer. With word width w, little-endian words x_i represent X = sum x_i 2^(wi). A multiplication certificate for m records product words y_i and the carry relation r_i + m x_i = y_i + 2^w r_(i+1), with r_(i+1) given by the local quotient. If the initial carry is zero and each y_i < 2^w, their joined value is exactly the low w*length bits of mX (mulChain_low). 

For a power-of-two gap g=2^k≤w, an adjacent pair of product words is enough to check every g-bit window beginning in the first word. Doubling OR and AND by shifts 1,2,...,g/2 yields masks identifying windows containing a one and windows consisting entirely of ones. The check demands the first mask cover every valid start and the second mask contain none. Partial last words are handled by limiting starts to min(w,t+1-g), where t is the remaining valid length. The theorem product_windows proves that every g-bit window of the *actual product* inside the certified valid length contains both bits. No giant numeral is evaluated. SegmentOK exposes the next word at a batch boundary; segmentOK_append and mulChain_append compose batches without losing cross-boundary windows or the multiplication carry.

Locally checked using Lean 4.36.0-rc2 (b35cb10cf2ced51a2fd1880cfdbf75c71ab7a35a), exact source blob 1c5a0a9f182830c50e002a2a626953a660b20f11. Exported theorem audits use only propext, Quot.sound, and (for mixed-window transfer) Classical.choice. This is a generic arithmetic lemma, not an original-machine exclusion or a concrete large certificate. [ChunkMargin.lean](ChunkMargin.lean) connects the arithmetic layer to the existing PowRunOK and AllBlockMargins interfaces.
