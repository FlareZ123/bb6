# Prefix-sharing TNF checker

Existing zipCheck restarts from blank at every split/last/cycle check. This module carries an exact successful zipper configuration from the last split. Its advance operation reuses the known run prefix if the requested index is later, and falls back to blank for earlier cycle entry. Refining an undefined slot preserves every successful prefix. The theorem prefixCheck_eq is unconditional and identifies the new checker with the existing source zipCheck. No new certificate trust boundary, no native_decide, no change to original proof assembly. Local Lean 4.36.0-rc2 preflight of the equivalence proof using exact zipper/checker definitions with uninterpreted FAR and weight routines passed, with propext and Quot.sound only. Source CI must confirm actual imports and benchmark large cylinders. switch_generated_checks.py preserves the original theorem types and rewrites the decision problem with the equivalence theorem. On raw58, 329449 nodes and a largest direct child of 62089 nodes motivate this work. No speedup claimed until measured.
