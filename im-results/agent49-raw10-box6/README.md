# Raw10 rectangle 6: exhaustive candidate classification

The original base-34 rectangle fixes A0..D1 to codes 8,14,11,7,17,4,9,2 and excludes 23 at E0. E1/F0/F1 are unrestricted. This is 375,000 tables, disjoint from rectangle 7. Code 0 is halt, -1 is a hole, and 1+4q+2w+r is an ordinary transition.

Extract source.tar.gz into an empty working directory. Run python3 search.py, python3 ngram.py, and python3 block_search.py in that directory. These emit the sparse partition and finite candidate witnesses. Search: 479 internal nodes, 479 halt leaves (max ordinary score 70), 3561 exact cycles, 4866 left translated cycles, 2047 right translated cycles, 356 open leaves. Of the latter, 318 are entirely ordinary tables and cannot halt; 36 have bit-ngram closure and two have 45-state two-cell block-ngram closure. The final two partials have suffixes (21,19,16,-1) and (21,19,4,-1). Both also admit finite 3-cell BlockFAR saturation (125 left states; 1501/1362 NFA nodes before quotient). No reachable in-block loop in the 3-cell FAR saturation. The generator branches on the first hole over every allowed value, so these witnesses cover the full rectangle. Translated cycles require complete forward ray equality and equality of the bounded backward excursion window. Each repeated segment then executes indefinitely by induction.

This is computational evidence, not source-accepted Lean coverage. A successful source audit would give ordinary score at most 70 and weighted score at most 75, including at most five initial blank delays. No global roster entry is removed yet. ## Source proof pipeline

The second archive `proof-source.tar.xz` contains `Box6Core.lean` (generic sound checker) and `emit_box6.py` (shard and certificate generation). Extract both archives into one directory, run search.py and ngram.py, then `python emit_box6.py . /absolute/path/to/im-results/agent13-block-far/generate.py`. The generator uses the existing three-cell BlockFAR kernel checker for four cases: E0=21, E1 in {7,19}, F0 in {4,16}, F1 unassigned. The two E1=7 cases were originally width-15 bit n-grams; BlockFAR saturation uses only 22 left states and 117/99 NFA states before minimization. The remaining 34 bit n-grams are checked with the existing sparse trie checker. All 25 E1 slices are covered by explicit finite cases; the largest E1=23 slice uses separately checked F0 subtrees. The checker validates every child from the allowed rectangle domain and the concrete accumulated partial table. It checks explicit halt assignments, translated cycles, all-ordinary leaves, sparse n-grams and exact equality to the four source-checked FAR partials. The final target is `BB6.Agent49Box6.raw10_box6_closed` and `residual_without_box6`.

Manual CI target `weighted-tnf-raw10-box6` rebuilds and checks the exact source closure. Until that succeeds the rectangle remains a candidate. No admitted proof or fixture is included in the committed source archive.
