# First-evaluator residue filters on affine predecessor rays

**Status:** source-derived arithmetic reduction; not yet a Lean-certified theorem. This is intermediate work, not a BB(6) solution.

## Setup

Use the original-source section map `highLevelNext` from
`im-results/agent49-parity623/Parity623Source.lean`. Its first coordinate is
even on the blank-root run. Write
[
u_j=\frac{3^j-1}{2}.
]
The source theorem `evalA_none_iff_ternaryCongruence` says that the evaluator
`evalA A k m` fails exactly when
[
k\bmod 3^{A+1}=u_A.
]

For a candidate state (D(b,e)), assume (b>0) is even. Put
(Delta=b-e). The branch selected by `highLevelNext` determines the first
`evalA` call. The third argument (m) does not affect failure, so only
((A,k)) is recorded below.

## Exact first-call cases

Since (b) is even, (Delta) has the parity of (e).

| Parity of (e) | Gap (Delta) | First evaluator ((A,k)) | Immediate-failure residue |
|---|---:|---|---|
| odd | (Delta\le 3) | ((e+4-b, b-2)) | ((b-2)\bmod3^{e+5-b}=u_{e+4-b}) |
| odd | (Delta\ge 5) | ((b-e-5, e+2)) | ((e+2)\bmod3^{b-e-4}=u_{b-e-5}) |
| even | (Delta\le 0) | ((e+1-b, b)) | (b\bmod3^{e+2-b}=u_{e+1-b}) |
| even | (Delta=2) | ((0, b-1)) | ((b-1)\bmod3=0) |
| even | (Delta\ge 4) | ((b-e-2, e+1)) | ((e+1)\bmod3^{b-e-1}=u_{b-e-2}) |

These formulas follow directly from the branch definitions:
- odd (e), (Delta\le3): `drainB (e+4-b) (b-1) 3`;
- odd (e), (Delta\ge5): `drainB (b-e-5) (e+3) 5`;
- even (e), (Delta\le0): direct `evalA (e+1-b) b (2*b+5)`;
- even (e), (Delta=2): `drainB 0 b 2`;
- even (e), (Delta\ge4): `drainB (b-e-2) (e+2) 2`.

The table characterizes failure of the **first** evaluator only. A successful
first call can be followed by a later failure inside `drainB).

## Positive-gap candidate is unique

For odd (e) and (Delta\ge5), put (A=\Delta-5). The residue condition is
[
(e+2)\bmod3^{A+1}=u_A.
]
Using (2u_A+1=3^A), this is equivalent to
[
2e+5\equiv3^A\pmod{3^{A+1}}.
]
Consequently
[
v_3(2e+5)=A,
\qquad
\frac{2e+5}{3^A}\equiv1\pmod3.
]
Thus a fixed odd base output (e=e_0) has at most one positive-gap
first-evaluator failure exponent (A), and hence at most one corresponding
positive-gap shift (Delta=A+5).

For even (e) and (Delta\ge4), put (A=\Delta-2). The same argument
gives
[
2e+3\equiv3^A\pmod{3^{A+1}},
]
so
[
v_3(2e+3)=A,
\qquad
\frac{2e+3}{3^A}\equiv1\pmod3.
]
Again, there is at most one positive-gap shift that can make the first
evaluator fail.

## Negative-gap candidates are sparse

For odd (e) and (Delta\le3), set (A=e+4-b=4-\Delta). Then
(b-2=e+2-A), and the first-call failure condition is equivalent to
[
2e+5-2A\equiv3^A\pmod{3^{A+1}}.
]

For even (e) and (Delta\le0), set (A=e+1-b=1-\Delta). Then
(b=e+1-A), and the condition is equivalent to
[
2e+3-2A\equiv3^A\pmod{3^{A+1}}.
]

In either case, the left side has the form (C-2A), where (C) is fixed.
If (A_1<A_2) are two solutions, reducing their congruences modulo
(3^{A_1+1}) gives
[
2(A_2-A_1)\equiv3^{A_1}\pmod{3^{A_1+1}}.
]
The left side is even, whereas the least positive representative
(3^{A_1}) is odd. The next positive representative is
(4\cdot3^{A_1}), so
[
A_2-A_1\ge2\cdot3^{A_1}.
]
Therefore negative-gap first-failure exponents, if there are several, are
separated by an exponentially growing gap. This is a strong sparsity bound,
though it does not yet show that the root's parameter avoids them.

## Substitution along affine rays

For a right ray, the source shift theorem gives an output of the form
[
D(b,e)=D(b_0+2t,e_0).
]
Hence
[
\Delta=b_0+2t-e_0,
\qquad
t=\frac{e_0-b_0+\Delta}{2}.
]
Each admissible first-call failure gap (Delta) therefore determines at most
one ray parameter (t).

For a left ray, the output has the form
[
D(b,e)=D(b_0+t,e_0),
]
so
[
\Delta=b_0+t-e_0,
\qquad
t=e_0-b_0+\Delta.
]
The same residue table applies. The remaining task is to compare these sparse
candidate shifts with the actual parameters generated by the blank-root
orbit, and then control all later `drainB` calls after a successful first
evaluator.

The finite root trace has two states in the logarithmic gate:

  Here (26\bmod9=8\ne u_1=1).
- (D(108,101)): odd (e), (Delta=7), so ((A,k)=(2,103)).

Both first evaluators succeed. This is consistent with the observed root
transitions, but the nonfailure of the first call alone is not a proof that
the remaining drain succeeds.

## Finite root-ray candidate audit (computational evidence)

An independent BigInt translation of the source transition was used to enumerate
the first 1,000 states of the blank-root orbit. For each old-cone state after
index 9, I reconstructed the corresponding boundary-ray output and enumerated
the first-evaluator failure shifts from the congruences above. The search
included exponents through
\(\lceil\log_3(e_0+10)\rceil+5\), a deliberately generous finite cap; the
exact relationship between this cap and the source logarithmic gate should
still be formalized.

| Quantity | Count |
|---|---:|
| Right-ray old-cone states | 419 |
| Left-ray old-cone states | 259 |
| Total candidate first-call failure shifts | 222 |
| Actual root parameters equal to a candidate | 0 |

The closest candidate separations in this finite audit were:
- right ray, index 13: (a=122), actual (t=96), candidate (t=134);
  separation (38), with (38^2-122=1322);
- left ray, index 11: (d=38), actual (t=231), candidate (t=105);
  separation (126), with (126^2-38=15838).

Thus the finite trace exhibits a stronger pattern than mere non-equality:
the actual ray parameter is at least the square root of the smaller boundary
coordinate away from every enumerated first-call failure candidate. This is
not yet a theorem, and the simulator is an independent translation rather
than a kernel-checked computation. A useful next step is to reproduce the
candidate enumeration from the Lean source and prove a root-specific
separation invariant.
