# First-hole TNF refinement witnesses for six accepted Cryptids roots

The six existing source-connected nonhalting proofs are reusable at genuine first-hole TNF nodes: each table with its halt row erased is reachable from the authentic `1RB` root in ten ordinary refinements, without introducing a state out of canonical order. The witness is for the *full* expansion before decider pruning. It does not assert that a particular external decider queue retains all these nodes, or close their siblings or the root.

[FirstHolePath.lean](FirstHolePath.lean) defines a first-hole path with the exact original `knownRun`, current unassigned slot, introduced-state bound and least-fresh-label rule. The Boolean checker obtains transitions from the target table, checks the known run to the actual queried row at every step and verifies the endpoint extensionally over all twelve input rows. `checked_from_root` converts an accepted schedule into a path to `forgetHaltRows m` at cut 6.

[CryptidsFirstHolePaths.lean](CryptidsFirstHolePaths.lean) checks all six explicit schedules by kernel `decide` using the literal tables from `Cryptids608NonHalt`. It targets the existing nonhalting leaf adapter, not a second copy of the upstream nonhalting proofs. The last first-hole times are 52, 35, 38, 15, 22, 62 ordinary moves respectively; every path has ten refinements after A/0. Consequently each encountered halt sibling has weighted score at most 68 by the previously proved five-step blank-delay bound, but the other ordinary siblings remain separate proof obligations.

**Local verification:** Lean 4.36.0-rc2 (b35cb10cf2ced51a2fd1880cfdbf75c71ab7a35a) compiled the checker and all six reachability proof bodies against copied source-equivalent definitions of Frontier's tape semantics, WeightedTNF's known run, firstOneCylinder, forgetHaltRows, and the six literal table definitions. All nine printed profiles were [propext, Quot.sound], no sorryAx, and the run took 1.65 s. The exact original imported closure is not yet checked: direct Git checkout failed DNS in this runtime.
