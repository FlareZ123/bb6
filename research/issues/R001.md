## Approach and discriminating tests

One task reconciles exact original tables, designated roots, dates and provenance. A distinct task checks a small candidate shortlist against primary analyses/deciders. Preserve unmapped/disputed changes. Classify a new decision, imported result, equivalence and enumeration change separately.

## Useful outcome

A reproducible rooted concordance and shortlist justified by concrete missing mechanisms, reusable structure or approachable gaps. Stop the initial audit when it supports selection; avoid endless filename collection. Unknown external status stays unknown. Review before expanding the census.

## Practical verification

Start with read-only source comparison and a small reproducible local transformation. No large enumeration/CI. Any source check must name the particular status assertion it validates.
