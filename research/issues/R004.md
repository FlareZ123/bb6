# R004: historical cross-root method programme

**Status: retired umbrella question.** The original R004 project compared transferable methods across structurally different six-state blank-root machines. Its [complete historical programme record](../archive/v1/issues/R004.md) preserves the source inventory, proposed tests, failed approaches and reviewers. No slots or shared allocation are active.

The reusable scientific question remains: **can an original-source theorem for one root transport to another while preserving the actual blank tape, exceptional returns and halting semantics?** Test each candidate mechanism in its own primary dossier. Particularly relevant starting points are [S4's source bridge](../../im-results/agent5-s4-source-bridge/README.md), [Cryptid D's original physical regular-return results](../../im-results/agent2-cryptid-continuity/README.md), and [the #623 inverse exploration](../../im-results/agent8-623-inverse/README.md).

A synthetic-input transfer, finite trace or repeated quotient count is insufficient to settle a new blank-root machine. Record the exact mathematical source, original root hypotheses, nontrivial mechanism, first falsifier, and strongest verified theorem alongside that mechanism's dossier.
