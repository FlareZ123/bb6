## Why this is a distinct scientific pilot

Existing R001 audits **dates and root statuses**, R004 studies **individual arithmetic cryptid mechanisms**, Agent3 portfolio conjugacies preserve table isomorphisms, Agent42 short-prefix normalization changes the root semantically, and Agent48's fixed champion bridge illustrates a **finite eventual state-and-tape merge**. This pilot tests that last mechanism systematically on historically *unresolved* roots of different initial states with the same table. Finite coalescence is stronger than common unrooted table isomorphism: it proves equality of future raw-TM behavior modulo an actual spatial shift, including exact halting-time offset.

## Test and scope

Start with dated pinned 2026-10-16 663-root ledger and its 145 multi-root table families. Simulate each distinct canonical-table blank root a fixed bounded number of primitive steps, represent whole finite marked tape relative to head, and search **cross-root** collisions. Independently replay every candidate with a different exact simulator, confirm literal table, source roots, and exact time relation. Prefer nontrivial pairs with both roots remaining in the current 608 catalogue. If found, write source-connected Lean transport proof for one such pair and map effects on the open frontier. Do not claim 663 is the current undecided list.

Null result after bounded raw search is informative only about that specific cutoff, never a proof of no eventual coalescence. If no promising current-root collision appears, shelve pilot or redirect to a genuinely different mechanism rather than spending a second slot on larger routine sweeps.

## Outcome/compute

Bound first scan at **800 raw steps per root**, extend to **3000** only for a well-defined missed class if justified by observed collisions. At most ~2 million primitive transitions, no expensive CI unless a concrete candidate is found. Preserve code, counts and exact source version under `im-results/`.
