# Durable reviews

Add uniquely named review files using [the template](../REVIEW_TEMPLATE.md). Link them from the root programme's grant or evidence/handoff. The canonical pending queue is each root's review_requested field, surfaced by the read-only board tool.

Preserve earlier decisions, objections and negative evidence even after a request is cleared. A later decision names what it supersedes and why. Ordinary independent peers may renew justified work; specifically critic-escalated restrictions remain for future critics. No review requires the installing Super-Critic to return.
