# BB(6): mathematical result map and open proof obligations

**Research synthesis, 2026-11-08:** The exact six-state, two-symbol Busy Beaver step value is **unknown**. This repository has not established a complete blank-start decision for the remaining holdouts, a global six-state upper bound, or a complete maximum-attaining certificate. A source-verified *necessary gateway exclusion* for one machine is not a decision of that machine.

## External BB(6) lower-bound baseline (not a repository theorem)

BusyBeaverWiki currently identifies `1RB1RA_1RC1RZ_1LD0RF_1RA0LE_0LD1RC_1RA0RE` as the BB(6) champion, discovered by mxdys on 25 June 2025, and reports the published step lower bound `S(6) > 2 ↑↑↑ 5`. Its machine page gives an approximate halting-time analysis between `2 ↑↑↑ 5` and `2 ↑↑↑ 6`, plus a separate, more precise sigma-score estimate `10 ↑↑ 10 ↑↑ 10 ↑↑ 8.10237`. The sigma score is not the primitive step count. The wiki links a Rocq analysis at [busycoq/SOBCv5.v](https://github.com/ccz181078/busycoq/blob/3f302b87f5fb933c46e97672ffbb6907f373fb6e/verify/SOBCv5.v#L10210-L11283).

This is external published evidence, not a repository theorem. The repository's [Agent 48 champion-root bridge](../im-results/agent48-champion-root/README.md) formalizes a conditional machine equivalence; it does not yet import the unconditional external halting proof or prove the exact primitive step count. The source links and notation distinctions are recorded in [the external baseline note](../resources/BB6-current-frontier-2026-11-06.md).

## Historical result notes and publication status

The original eighteen standalone gateway notes comprise three Machine C component results and fifteen P1 entries. The separately derived 8 November source-indegree/distribution theorem is a structural counting result, rather than an additional gateway exclusion. The Machine C components are integrated by the synthesis above. Nine Machine C reports were moved, with their full proofs and provenance preserved, to the [publication qualification archive](../im-results/machine-c-publication-audit/README.md) because they are quotient-known or specializations of broader source theorems. **The inclusion of any component note is not an independent claim of external priority.** An academically publishable contribution requires theorem-level comparison with the strongest repository and external work, a coherent synthesis, and traceable verification.

The former approximately 19-kB, certificate-by-certificate index is preserved in the [historical catalogue](../im-results/legacy-results-index-20261105-critic.md), whose links now point to the retained results or the qualification archive. Larger results should be presented through synthesis documents that state the new method, existing baselines, exact remaining quantifier, and source chain.

**Research aim:** Prove a complete authentic blank-root halt/nonhalt decision, or a proof-carrying exhaustive six-state maximality certificate. Parameter counts, longer finite traces, synthetic predecessor counts and disconnected necessary conditions provide research tools; none alone measures a fraction of BB(6) solved.
